| 첫 보도 표시 `first_report_flag` (p45) | ❌ (선택) | 위 절충안을 쓰면 같이 생김 |
| 출처 등급 `source_tier` (p45) | ❌ | 통신사 / 언론사 / 집계 사이트 구분 없음 |

| Reddit 하루 피처 6개 중 `author_count`, `tone_sd`, `new_author_share` (p44) | ❌ | 채민 baseline 은 글 수·급증·지속만 있음. 강의는 "글 수 대신 작성자 수로 평균내라"고 함 |
| 집계 규칙이 결과를 바꿈 (p14) | 🟡 | 채민 v6 는 비율 하나만 씀 → w5-1 표의 집계 규칙 항목 참고 |
| TF-IDF, 임베딩, BERT (p23–41) | 🟡 | A 가 TF-IDF 로지스틱을 해 봄(`text_big`, `text_dir`, 효과 없음). 임베딩·FinBERT 는 안 함 |

| 강의 내용 (쪽) | 우리 상태 | 근거 / 할 일 |
|---|---|---|

| tone 과 polarity 구분 (p21) | ✅ | 채민 v6: 주가 반응·투자의견을 사업 사건과 따로 저장 |
| tone 말고 다른 양: 관심·불확실성·새로움·분산·사건 (p22) | 🟡 | 관심 ✅, 사건 ✅(v6), 불확실성 🟡(v6 의 사건 상태), **새로움 ❌, 분산 ❌** |
| 기사 수가 방향보다 변동성을 예측 (p25, Antweiler & Frank 2004) | ✅ 결과는 같음, **인용은 없음** | 채민 baseline: 급등락과 상관 0.08~0.14, 수익률과 0.00. B: 크기 IC 0.29 vs 방향 IC 0.03 |
| 텍스트는 방향이 아니라 위험을 예측 (p27, Kogan et al. 2009) | ✅ 결과는 같음, **인용은 없음** | 위와 같음. 발표 9장("크게 찍기의 비대칭") 옆에 넣으면 좋음 |
| 기사 수 baseline 이 기준 (p39) | 🟡 | A 가 기사 수 ablation 은 했지만, 채민 LLM 피처와의 직접 비교는 아직 |
| 집계 규칙을 2개 이상 보고 (p16–17) | ❌ | 채민 v6 는 비율 하나. 이진 플래그(any above / any below)라도 같이 |
| 클래스별 recall, 정확도만 보지 않기 (p12) | ❌ | 채민 검수는 직접 고른 사례(C01–C12, D01–D20) 위주. 무작위 표본 라벨링 필요 |
| 모델 기억(contamination) 점검: 이름·날짜 가리고 두 번 채점 (p35–37) | ❌ | 기간 2024–2026 이 Gemini 학습 기간과 겹칠 수 있음. 일부만 가려서 다시 돌리기 |
| 프롬프트 민감도: 표현을 바꿔서 결과 비교 (p38) | ❌ | v6 프롬프트 하나만 씀 |
| 시간대 정리, 16:00 이후는 다음 세션 (p34) | ✅ | 이번에 확인: 시간봉 시각이 ET 로 일정(서머타임 전환 주에도 마지막 봉이 08:00) |
| 사전(단어 목록) 방법의 한계, Loughran-McDonald (p5–7) | 🟡 | A 의 사건 단어 목록은 직접 만든 것. 금융 전용 사전(LM)은 안 씀. 효과가 없었으니 발표에 "써 봤다" 정도만 |
| FinBERT (p8–15) | ❌ / 확인 필요 | 10/4 회의에서 채민 "감성 분석 모델 결과"를 공유하기로 했는데 레포에는 없음 |
