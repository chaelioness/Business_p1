## 4. 채민 LLM 피처 (최종본: 뉴스 v6 · Reddit v4) — 강의 기준 요약

**무엇이 왔나**

|---|---|---|
| 기간 | target 2024-08-14 ~ **2026-05-29** (fold4 포함, 6/1 이후 없음) | 같음 |

| 피처 값이 있는 종목·날짜 | 2,331 / 22,450 (10.4%), fold4 283 / 3,000 | 4,362 (19.4%), fold4 549 |
| 시점 누수 | 통과 (`known_at < cutoff`) | 통과 (`since ≤ created_et < cutoff`), 좋아요·댓글 수 안 씀 |

10/6 발표자료 때 짚은 것 중 해결된 것: 열마다 분모 명시(피처 사전), 컬럼 이름 일치, 프롬프트 원문 포함(재현 가능), 모델 확인, 청킹 결정.

**강의 기준 평가**

| 구분 | 내용 |
|---|---|
| 강의와 맞는 설계 | 기업별 판단(w5-1 p20), tone/polarity 분리(p21), 사건 스키마(p22), 원문 인용 검증(w6-1 p40), 빈 날짜를 0 으로 안 채움(w5-1 p19), 감성 대신 사건을 고른 근거 제시(논조-수익률 상관 −0.004) |
| 실적 표 대조 (w5-1 p12) | 기대 비교 판단이 있는 관련 기사 중 같은 창에 실적 발표가 있는 860건을 `earnings.surprise_pct` 부호와 비교. **above → EPS 상회 94% (640/679).** below → EPS 하회 41% (55/134) 인데, 어긋난 79건 대부분이 "실적은 상회, **가이던스는 하회**" 기사라 실적 표에 없는 정보를 LLM 이 잡은 것. 실적 발표 358건 중 above/below 기사가 있는 건 232건(65%) |
| 갭이 모르는 방향 (w5-1 p25, p27) | ❌ B 도구 `check_text_dir.py`(train 기간, 기준은 10/5 에 미리 정함)로 9시 → 종가 움직임과 비교. **뉴스(above − below) 부호 일치 0.449, Reddit(bullish − bearish) 0.488** — 동전 던지기 수준. 뉴스가 갭과 반대인 139행에서 뉴스 쪽으로 간 비율 0.40 → 갭이 이김. 강의의 "텍스트는 방향보다 크기"와 같은 결과 |

| 고칠 것 (뉴스) | **검증 실패 104행(고유 제목 102개) 중 63개가 제목의 연속 공백·nbsp(줄바꿈 없는 공백) 문제**("Posts␣␣Earnings Results", "PC demand"). 나머지 39개도 대부분 기대 비교 구절의 인용 불일치로 보임. **102개 중 90개가 beat·miss·top·short of 같은 기대 비교 표현을 담은 기사** → 실적 결과가 가장 분명한 기사가 빠지고, 그 87개 종목·날짜의 `feature_*` 가 통째로 결측. 저장된 응답으로 공백만 정리해 **검증만 다시** 하면 63개는 살릴 수 있음(API 불필요). 최종 `extraction_spec.json` 의 normalizer 가 "기존 normalize_v6, 수정 없이 사용"이라, 10/6 발표자료의 "공백 복구"는 반영 안 된 것으로 보임 |
| 고칠 것 (Reddit) | 제외 36건 중 **27건이 "투자 의견과 대상 역할 불일치"** (LLM 이 bullish/bearish 를 줬는데 역할을 business 로 둔 경우라 검증에서 뺌). 예: "Intel is so cooked…", "QCOM has a chance to soar…", "Amazon Earnings tank incoming". **방향 의견이 가장 분명한 글이 빠지는 쪽으로 쏠림.** 나머지는 인용 불일치 4, 기업 연결 근거 부족 3, API 오류 1, 응답 미확인 1 |
