## 1. 제출 규칙의 예측 분해표 (P1)

**왜:** w6-1 p5–7 은 "읽을 수 있는 모델은 설명이 곧 모델이라 정확하다"고 합니다. 우리 규칙이 바로 그렇습니다. LightGBM 의 SHAP(근사·사후 설명)과 대비해서 "우리는 정확한 설명을 낼 수 있는 모델을 골랐다"를 보여 줄 수 있습니다.

**방법:** 행마다 아래 값을 한 줄로 냅니다. fold4 val 에서 세 행을 고릅니다: 급등락을 맞힌 행, 정반대로 찍은 행(A 발표 8장의 96행 중 하나), 출렁임 보정 때문에 등급이 바뀐 행.

| 단계 | 값 |
|---|---|
| 시간외 갭 | 마지막 시간외 봉 종가 ÷ 기준일 종가 − 1 |
| vol20 | 최근 20일 수익률 표준편차 |
| gap_z | 갭 ÷ vol20 |
| 출렁임 보정 | exp(−λ · x̃), x̃ = 표준화한 ext_range_z |
| s | gap_z × 보정 |
| 경계 | a, b (train 에서 고른 값) |
| 등급 | s 와 ±a, ±b 비교 |

**덤:** 출렁임 보정 때문에 등급이 바뀐 행의 비율과, 그 행들의 정답 분포를 같이 내면 ext_range_z 의 효과(+0.005)가 어디서 나오는지 보입니다.

## 2. 블록 permutation importance (P1)

**왜:** 지금 우리 중요도는 LightGBM gain 과 SHAP 뿐입니다. w6-1 p15–19 는 "검증 데이터에서, 여러 번, 시계열이면 블록으로 섞어라"고 합니다. 규칙에도 바로 쓸 수 있습니다.

**방법 (사전에 고정):**
- 대상: 제출 규칙, fold1~4 val. 열: `gap_z`, `ext_range_z`.
- 섞는 법 두 가지 (같이 보고):
  - **같은 날짜 안에서 종목끼리 섞기**: 그날 시장 국면은 유지하고 종목 정보만 끊음.
  - **종목 안에서 5거래일 블록으로 섞기**: 자기상관을 유지함 (p17).
- 30번 반복 → 점수 하락폭을 상자그림으로. 같은 그림에 "섞은 가짜 피처" 상자를 기준선으로 놓습니다.

**예상:** gap_z 는 크게 떨어지고, ext_range_z 는 0 근처에서 상자가 0 을 걸칠 수 있습니다. 그대로 보고하면 됩니다("작지만 일관된 개선"이라는 기존 결론과 맞음).

## 3. ICE / 그룹별 효과 (P1)

**왜:** w6-1 p21 예시처럼 평균 효과가 작아도, 그룹끼리 반대로 움직여 상쇄된 것일 수 있습니다. ext_range_z 의 평균 효과(+0.005)가 작은 이유가 이것인지 확인합니다.

**방법:** λ 를 0 → 폴드 값 → 2배로 바꿔 가며 그룹별 val 점수를 계산합니다. 그룹은 실행 전에 정합니다.
- 실적 발표가 있던 밤 / 없던 밤
- 처음 보는 종목 / 학습한 종목
- 시장 갭이 큰 날 / 작은 날 (|시장 갭| 상위 20%)

gap_z 와 ext_range_z 는 순위상관이 0.00 이라 ALE 까지는 필요 없습니다. gap 계열끼리 비교할 때만 ALE 가 필요합니다(p22).

## 4. 실적 표로 채민 LLM 추출 검증하기 (P1)

**왜:** w5-1 p12 의 정량 검증을 **라벨링 없이** 할 수 있습니다. `earnings` 표에 EPS 예상·실제·`surprise_pct` 가 숫자로 있으니, 채민 v6 의 `surprise`(above / below)가 맞는지 바로 대조됩니다. w6-1 p38–40 의 "숫자는 코드가, 인용은 LLM 이"와도 맞습니다.

**방법:**
1. 채민 `news_v6_valid_articles.csv` 에서 기대 대비 판단이 있는 기사만 고르고, 종목과 날짜로 `earnings` 와 붙입니다(실적 `known_at` 이 같은 창에 있는 것).
2. 표를 만듭니다: LLM above/below/in_line/mixed/unknown × EPS 서프라이즈 부호.
3. 일치율을 클래스별로 냅니다. EPS 는 상회인데 LLM 은 below 인 기사는 매출이나 가이던스 이야기일 가능성이 있으니 따로 표시합니다.

**이미 알게 된 것:** dev 기간 실적 358건 중 315건(88%)이 상회, 42건(12%)이 하회입니다. "기대 상회"는 평범한 일이라, `above_share` 가 높아도 방향 신호가 아닐 수 있습니다. 채민에게 전할 내용입니다.

## 5. 상관 피처 묶음 중요도 (P2)

**왜:** w6-1 p14·p18. A 발표 10장은 gap, gap_z, gap_rel_z 의 SHAP 를 따로 보여 줍니다. 셋은 같은 정보라 몫을 나눠 가져서 각각은 작아 보입니다.

**방법:** A 의 fold4 LightGBM(B 피처 26개)을 다시 만들고, 피처를 묶습니다.
- 갭: gap, gap_z, gap_rel_z, mkt_gap 등
- 변동성: vol·atr 계열
- 실적, 애널리스트, 텍스트

**보고:** 묶음별 SHAP 합과 묶음 permutation(묶음 전체를 같이 섞기, 30회). 메시지는 "방향 = 갭 묶음, 크기 = 변동성 묶음"으로 A 발표와 같고, 근거가 더 단단해집니다.

## 6. faithfulness 검사 (P2)

**왜:** w6-1 p23. "설명이 맞는지"를 검사하는 방법이고, 우리는 안정성·그럴듯함만 했습니다.

**방법:** LightGBM 에서 SHAP 상위 k개(k = 1, 3, 5)를 빼고 다시 학습한 점수 vs 무작위 k개를 뺀 점수(10회). 상위 k개를 뺄 때 훨씬 많이 떨어져야 설명이 충실한 것입니다.

## 7. 오래된 시간외 가격 표시 (P2)

**이번 점검에서 발견:** dev 기간 22,450행 중
- 50행(0.22%): 시간외 봉 없음 (2026-01-30 → 02-02, 이미 알던 것, 규칙은 보합)
- **105행(0.47%)**: 마지막 시간외 봉이 08:00 보다 이름 (04~07시). **2026-01-14~16 사흘에 48행이 몰림**
- **21행**: 장전 봉 없이 전날 장후 봉(17~19시)이 마지막. 갭이 전날 저녁 가격 기준

**할 일:** 규칙을 바꾸지는 않고, `gap_age_h`(cutoff 까지 남은 시간)를 기록해 이 행들의 val 성적만 따로 봅니다. 성적이 확실히 나쁘면 "오래된 갭은 보정을 더 세게" 같은 규칙을 **다음 데이터에서** 시험할 후보로만 남깁니다. 10월 평가 기간에 같은 결손이 생길 수 있으니 발표의 "한계"에 넣을 거리입니다.

## 8. 실적 서프라이즈 방향 × 갭 방향 (P2)

**왜:** w5-1 p22 의 "named events". B 는 "밤사이 실적은 갭에 이미 반영"으로 결론 냈는데, 이건 평균 이야기입니다. **서프라이즈와 갭이 반대 방향인 밤**(예: EPS 상회인데 갭 하락)은 다를 수 있습니다.

**방법 (실행 전에 고정):**
- 대상: 실적 발표가 있던 밤, dev 기간 358건.
- 그룹: 서프라이즈 부호와 갭 부호가 같음 / 반대.
- 지표: 갭 이후 움직임(09:00 가격 → 종가)의 부호. 반대 그룹에서 되돌림이 더 큰지.
- 하회가 42건뿐이라 표본이 작습니다. **결과가 좋아도 규칙에 넣지 않고** 발표의 "추가 관찰"로만 씁니다.

## 11. 확신도가 낮으면 급등락을 덜 찍기 (P2)

**회의 내용:** 벌점의 51% 가 급등락을 정반대로 찍은 3% 행에서 나오니, 방향이 애매하면 급등락 대신 상승·하락으로 찍자는 제안(재은). LLM 으로 확신도를 받는 방안도 나옴.

**이미 있는 것:** ext_range_z 가 바로 이 역할입니다. 시간외에 크게 출렁인 갭은 "덜 믿고" s 를 줄여 급등락 경계를 덜 넘게 합니다. 발표에서 "확신도 장치를 이미 하나 넣었다"로 연결할 수 있습니다.

**더 해 볼 것 (실행 전에 고정):** 정형 데이터로 만들 수 있는 새 확신도 후보는 하나만 시험합니다.
- 7번의 갭 신선도 `gap_age_h` (오래된 가격일수록 덜 믿음)
- 장후·장전 움직임의 방향 일치도는 B 실험에서 이미 해 봄(`new_agree3`, "갭의 일부라 이미 들어 있음"으로 뺌) → 다시 하지 않음

방식은 ext_range_z 와 같은 곱하기 `s = gz · exp(−λ·x̃ − μ·z)` 이고, μ 는 train 으로만 고릅니다. A 발표 9장에서 크기 신호로 급등락 경계를 옮기는 실험(δ)은 효과가 없었으니, 확신도도 효과가 작을 가능성이 큽니다.

## 12. 처음 보는 종목 점수가 낮은 이유 (P2)

**회의 내용:** fold4 처음 보는 10종목 0.418 vs 전체 0.515. 종목 과적합일 수 있으니 일반화를 따져 보자(재은).

**B 쪽에서 확인할 것:** 규칙은 종목 이름을 안 쓰고 자기 vol20 으로 나누기만 해서, 구조상 종목 과적합은 작아야 합니다. 그래서 "운인지, 데이터 성질 차이인지"를 정형 데이터로 나눠 봅니다.
- 낮은 종목(CVS, NFLX, WELL)과 높은 종목(BKNG, BA)의 시간외 봉 수, 평균 |gap_z|, ext_range_z, 실적일 수, 갭 이후 되돌림 비율을 한 표로
- 같은 10종목을 fold1~3 에서도 채점해 종목 순위가 유지되는지 확인. 유지되면 데이터 성질, 바뀌면 운
- 학습에서 다른 10종목을 빼고 다시 돌렸을 때 점수 차이가 비슷한지 (빠진 종목 조합만 바꾸기)
