## 왜 안 올랐나 — 실험에서 확인한 것

1. **실적 피처는 지금 설정으로는 모델이 쓸 수 없음.** 잎 최소 300행인데 실적 발표일은 학습 구간에 150~300행뿐 → `earn_timing` 은 점수가 V1 과 소수점까지 같음.
   잎 최소 100 으로 낮추고 실적 묶음(earn_now + earn_timing + earn_hist_absr)을 넣어도 +0.0014 (노이즈 안).
2. **분포맞춤 디코딩(기대 등급)은 크기 정보를 못 씀.** "크게 움직이는데 방향 모름"은 급하락·급상승 확률을 같이 올려 기대 등급이 그대로라 점수에 안 나타남.
   그래서 방향 × 크기 디코딩(급등락 여부와 방향을 따로 자름)도 시험: V1 0.381 로 기대 등급 디코딩(0.404)보다 낮고, 이 디코딩에서도 채택 후보 없음
   (mkt_absgap · gap_disp 는 fold4 만 +0.009, 평균은 그대로).
3. **방향 후보는 gap 계열과 겹침.** gap_onz 는 gap_z 와 0.99, gap_rank 는 gap_rel_z 와 0.88.

# 3차: 2단계 구조 (2026-10-02, `exp/r03_twostage.py`)

방향과 크기를 따로 정하는 구조 세 가지. K(급등락 %)·F(보합 %)는 fold1~3 으로 고르고 fold4 로 확인, 시드 3개 평균.
- T1 규칙 + 크기 모델: 방향·보합은 갭 규칙, 규칙이 보합 아닌 종목 중 P(급등락) 상위를 급등락으로
- T2 방향 모델 + 크기 모델: P(급등락) × 방향 확신도 상위를 급등락, 나머지는 P(상승)으로
- T3 갭 방향 + 크기 × 갭 확신도: P(급등락) × |gap_z| 순위 상위를 급등락, 나머지는 gap_z 로
크기 모델: 이진 LightGBM(급등락 여부), 변동성·실적·시장 요동 20개, 잎 최소 100. 방향 모델: 이진 LightGBM(상승 여부), 갭 계열 13개.

## 왜 안 넘나 — 단계별 모델의 실력 (val AUC, 시드 0)

| | fold1 | fold2 | fold3 | fold4 |
|---|---:|---:|---:|---:|
| 크기 모델 (급등락 가려내기) | **0.766** | **0.778** | **0.754** | **0.788** |
| atr14 하나 | 0.699 | 0.741 | 0.690 | 0.746 |
| \|gap_z\| 하나 | 0.675 | 0.610 | 0.643 | 0.668 |
| 방향 모델 (상승 맞히기) | 0.638 | 0.641 | 0.647 | 0.673 |
| gap 하나 | 0.657 | 0.653 | 0.645 | 0.680 |

- **크기는 모델이 확실히 더 잘 맞힘**: 피처 여러 개를 합친 크기 모델이 atr14 하나보다 AUC +0.04~0.07.
- **방향은 gap 하나와 같거나 낮음**: 방향 모델이 gap 하나를 못 넘음 → 방향 정보는 사실상 시간외 갭이 전부 (EDA 결론과 같음).
- 점수는 급등락을 **맞는 방향으로** 찍어야 오르는데, 급등락을 잘 가려내도 방향은 갭 수준(AUC 0.65~0.68)이라
  틀린 방향 벌점(최대 64)에 막힘. 그래서 크기 실력이 점수로 잘 바뀌지 않음.

## 정리

- 현재 데이터(B 정형 피처)로는 **방향이 병목**. 크기 쪽 개선(피처·2단계)은 점수로 이어지지 않음.
- 실전 후보는 두 가지가 비슷: 갭 규칙(4폴드 0.423, fold4 0.493) vs 1단계 모델 + 급등락 34%(0.417, fold4 0.499).
  차이는 노이즈 수준이고, 폴드마다 이기는 쪽이 다름 (규칙은 fold1, 모델은 fold2~4).
- 점수를 더 올리려면 **갭이 모르는 방향 정보**가 필요함. B 표(일봉·실적·애널리스트)에서는 찾지 못함 → C 의 뉴스·Reddit 이 방향을 보태는지가 남은 질문 (지금까지 EDA 는 "방향 없음").

- R2 내리기: **q=0(안 내림)이 최선**. 내릴수록 정밀도는 오르지만(0.23→0.33) 점수는 계속 떨어짐. 갭이 큰데 크기 모델이 "조용하다"고 본 경우도 실제로는 급등락이 충분히 나옴 → 갭이 크기 모델보다 강한 신호.
- R3 실적일 경계: +0.0005 이하, 노이즈 수준. 실적일 행이 적고(약 1~2%), 실적일엔 갭 자체가 이미 커서 원래 경계로도 대부분 급등락으로 찍힘.
- 조합(R3 s=0.5 + R2 q=0) = R3 와 같음.

## 정리

# 7차: 모든 피처 × 세 가지 붙이는 방식 (2026-10-02, `exp/r07_gapfeat_all.py`, `exp/r07b_check.py`)

표의 모든 숫자 피처 70개 + 표 칼럼으로 만든 새 후보 5개(장전·장후 움직임 ÷ vol20, 장후·장전·갭 방향 일치 수,
베타로 시장 몫을 뺀 갭, 시간외 봉 수 로그) = 75개를 세 방식으로 gap_z 에 붙임 → 225개 조합.

- 더하기 s = gz + β·σ·x̃ (방향 보탬) / 곱하기 s = gz·exp(β·x̃) (갭을 얼마나 믿을지) / 같은방향 s = gz·exp(β·x̃·sign(gz))
- β 는 폴드마다 train score 최대. 채택 기준은 6차와 같음.

## 결과: 기준 통과 3개 — 하지만 우연 수준

| 조합 | β (fold1~4) | Δ평균 | Δfold4 | 상승 폴드 |
|---|---|---:|---:|---:|
| dow (요일) 더하기 | −0.05 ×4 | +0.007 | +0.004 | 4 |
| vol_5_20 (5일 ÷ 20일 변동성) 같은방향 | 0.2/0.1/0.1/0.2 | +0.005 | +0.002 | 3 |
| ext_range_z (시간외 고저 폭) 곱하기 | −0.5/−0.3/−0.3/−0.2 | +0.005 | +0.004 | 4 |

**우연 기준선** — 피처 값을 무작위로 섞어(정답과의 관계를 끊고) 같은 절차를 2번 돌림:
225개 중 **4개, 1개가 기준 통과**, Δ평균 최대 +0.008, +0.006. 섞은 mkt_gap_z 가 진짜 dow(+0.007)보다 높았음.
→ 진짜 데이터의 통과 3개(최대 +0.007)는 **아무 관계 없는 피처로도 나오는 수준**. 225개를 시험하면 이 정도는 우연히 통과함.

**셋을 함께 넣으면**: gap_z 규칙 0.438 → dow 0.445 → + vol_5_20 0.450 → + ext_range_z 0.450 (fold4 0.501).
하지만 이 셋은 4폴드 결과(fold4 포함)를 보고 고른 것이라 이 숫자는 부풀려져 있음. ext_range_z 는 함께 넣으면 β 부호가 폴드마다 바뀜(0.2/0/−0.3/−0.3).

## 해석

- dow: 요일 번호에 비례해 점수를 깎음(주 후반일수록 하락 쪽으로). 경제적 근거가 약하고 요일을 숫자로 다룬 것이라 우연일 가능성 큼.
- vol_5_20: 최근 변동성이 평소보다 커졌을 때 갭을 더 믿음. β 부호가 4폴드 모두 같고 해석도 되지만 크기가 우연 기준선 안.
- ext_range_z: 시간외에 많이 흔들린 갭은 덜 믿음. 6차(더하기)에서도 같은 방향이었지만, 다른 피처와 함께 넣으면 부호가 흔들림.

## 정리

- **채택 0개 (확신할 수 있는 것 없음).** 근거가 확실하다고 말하려면 우연 기준선(+0.006~0.008)보다 확실히 커야 하는데 못 미침.

| 3 탈락 | 그 밖 88개 피처 × 3방식, 여러 개 함께(M1~M3), 규칙 모양 변형 | | | 우연 기준선 안이거나 fold4 에서 하락 |

**gap_z 규칙 + ext_range_z: 4폴드 0.444, fold4 0.4995, 처음 보는 종목 0.350.**

## 해석 (회의용)

- 시간외 갭은 다음날 방향의 거의 유일한 정형 신호. 같은 갭이라도 **종목 평소 변동성 대비**로 봐야 하고,
  **밤사이에 크게 출렁이다가 도착한 갭**은 정보가 아니라 잡음(유동성 낮은 시간외 체결)일 가능성이 커서 덜 믿어야 함.
- 나머지(추세·되돌림·실적·애널리스트·시장 국면·동종 종목 갭)는 갭에 이미 들어 있거나 기간마다 방향이 바뀜.

# 12차: 두세 개 조합을 빠짐없이 (2026-10-02, `exp/r12_combo.py`)

후보 102개 피처 × 3방식. 폴드마다 train 내부 검증으로 상위 12개를 고르고, 그 안의 2개 조합 66개, 3개 조합 220개를 전부 시험.
β 는 하나씩 시험할 때 정한 값 그대로. 내부 검증 최고 조합을 val 로 확인.

| 내부 검증으로 고른 것 | Δ평균 (gap_z 규칙 0.438 대비) | 상승 폴드 |
|---|---:|---:|
| 1개 | +0.000 | 1 |
| 2개 | −0.001 | 3 |
| 3개 | −0.013 | 0 |
| (참고) 섞은 가짜 피처로 같은 절차, 2개 / 3개 | −0.020 ~ −0.005 / −0.012 ~ −0.005 | 0~1 |

- **내부 검증에서는 개수를 늘릴수록 크게 오름**(1개 +0.01~0.06 → 3개 +0.03~0.09), **val 에서는 개수를 늘릴수록 떨어짐**.
- 내부 검증 상위는 대부분 시장 전체 피처(mkt_ret5, mkt_vol20, mkt_ret1, dow): 직전 120일 시장 분위기에 맞는 것. 폴드마다 다르고(같은 mkt_ret5 가 폴드마다 부호가 바뀜), 4폴드 모두 후보에 든 조합은 없음.
- 모든 조합의 val 분포: fold1 은 298개 조합이 **전부** 하락, fold2 는 5~8%만 상승. 내부·val 상관은 −0.31 ~ +0.51 로 들쭉날쭉.
- 진짜 피처로 고른 조합과 가짜 피처로 고른 조합의 결과가 같은 수준.
→ 두세 개씩 조합해도 남는 것 없음. ext_range_z 는 내부 검증 120일만으로는 상위 12개에 들지 못함(효과가 작아 짧은 구간으로는 안 보임, 긴 train 전체로 봐야 보임).
