## 1. 피처 추출 방식

### 시점 원칙 (누수 방지)
- 모든 데이터는 `day.daily / day.price / day.earnings / day.analyst` 로만 읽음 → `known_at < 대상일 09:30` 인 행만 나옴.
- 피처 표는 `lab.cv.feature_table` 로 만들어서 `guard` 가 씌워진 상태에서만 계산. 누수 검사 통과.
- 종목 이름·날짜를 코드에 넣지 않음. 종목마다 크기가 다른 값은 **자기 변동성(vol20)으로 나눈 z값**으로 만듦.
- 시장 값 = 그날 daily 에 보이는 종목들의 동일가중 평균.

### 시간 구간
| 이름 | 구간 | 쓰는 곳 |
|---|---|---|
| 기준일 | 대상일 직전 거래일 (종가 16:00 확정) | 일봉 피처 전부 |
| 장후 (post) | 기준일 16:00 ~ 20:00 | post_ret, post_n |
| 장전 (pre) | 대상일 04:00 ~ | pre_move, pre_late |
| 시간외 전체 | 기준일 16:00 이후 post + pre 봉 | gap, ext_range_z 등 |
| 마지막 시간외 봉 | 대상일 08:00 봉 (09:00 공개) | gap 의 "현재 가격" |
| 밤사이 이벤트 | 기준일 16:00 ~ 대상일 09:30 | earn_now, an_now_* |

### 핵심 두 피처 계산
```
gap        = 마지막 시간외 봉 종가 ÷ 기준일 종가 − 1
vol20      = 최근 20거래일 일간 수익률 표준편차
gap_z      = gap ÷ vol20
ext_range_z = (시간외 봉 최고가 − 최저가) ÷ 기준일 종가 ÷ vol20
```
코드: `work/b/gapz_rule.py` 의 `build_gapz(day)` (전달용, 두 피처만). `features_b.py` 의 `build_b(day)` 에도 같은 값이 들어 있음.

### 결측
| 피처 | 결측률 | 결측 행 (A 폴드 전체 22,450행) |
|---|---:|---:|
| gap_z | 0.22% | 50 |
| ext_range_z | 0.22% | 50 |

- 50행 전부 **기준일 2026-01-30(금) → 대상일 2026-02-02(월)** 하루, 50종목 모두. 그 밖의 날짜는 결측 없음.
- 원인은 **원본 price 데이터 누락**: 1/30 장후 봉 0개, 2/2 장전 봉 0개(평소 각 150개, 290개 안팎). 같은 이틀은 정규장 봉도 평소의 1/5~1/2 수준. 일봉은 정상.
- 처리: 규칙에서는 갭이 없으면 보합(2). LightGBM 에 넣을 때는 결측 그대로 두면 됨 (따로 채울 필요 없음).
- ext_range_z = 0 (시간외 봉이 하나뿐) 인 행은 없음.

### 최종 규칙
```
x̃  = (ext_range_z − train 중앙값) ÷ train 표준편차, ±5 로 자름, 결측 0
s   = gap_z × exp(−λ · x̃)          λ: train score 최대로 고름 (폴드마다 0.05~0.3). 실험(경계 후보 .5~)에서는 0.2 고정도 4폴드 모두 상승
경계 a < b: |s| 의 분위 [.1 .2 .3 .4 .5 .6 .7 .8 .85 .9 .95 .975 .99] 중 train score 최대인 쌍 (재은님 기준선과 같은 후보)
s ≥ b → 4 급상승 / s ≥ a → 3 상승 / s ≤ −a → 1 하락 / s ≤ −b → 0 급하락 / 그 밖·결측 → 2 보합
```
- 경계 a 가 작게 잡혀서(폴드마다 |s| 하위 10% 수준) 보합은 거의 안 찍음 (50종목 중 3~5개).
  점수에서 정답이 보합인 행은 가중치가 0 이라, train score 를 최대로 하면 이렇게 됨.

## 2. 선택 방법

### 평가
- 점수: `src.score` (가중 kappa 류, 0 = 우연). 처음 보는 10종목은 학습에서 빼고 val 에만.
- 비교 기준: gap_z 규칙. 모델이 있는 실험은 시드 3개 평균.
- 피처를 gap_z 에 붙이는 방식 세 가지 (피처는 train 기준 표준화):
  - **더하기** `s = gz + β·σ·x̃` — 방향 정보를 보탬
  - **곱하기** `s = gz · exp(β·x̃)` — 그날 갭을 얼마나 믿을지
  - **같은방향** `s = gz · exp(β·x̃·sign(gz))` — 피처가 갭과 같은 방향이면 더 믿음
- β 는 폴드마다 **train 으로만** 고름 (val 안 봄).

### 채택 기준 (실험 전에 정함)
1. 4폴드 평균 +0.005 이상
2. 4폴드 중 3폴드 이상 상승
3. fold4(2026-03~05, EDA 와 안 겹침)에서 하락 없음
4. **우연 기준선보다 커야 함**: 피처 값을 행 사이에서 무작위로 섞어 같은 절차를 돌리면, 225개 조합 중 1~4개가 기준 1~3을 통과하고 최대 +0.008 까지 나옴. 많이 시험할수록 우연 통과가 생기므로, 앞 실험에서 먼저 발견되고(사전 근거) 부호가 4폴드 모두 같은 것만 인정.

## 4. 선택 이유

### 왜 gap_z 인가
- 정답 수익률(전일 종가 → 당일 종가)에 밤사이 갭이 들어 있고, 9:30 에 보이는 시간외 갭이 전체 분산의 약 30% 를 설명함.
- 같은 1% 갭이라도 평소 2% 움직이는 종목과 0.5% 움직이는 종목은 의미가 다름 → 자기 변동성으로 나눔.
- 분모 9가지(vol5, vol20, vol60, atr14, √(vol20·vol60), vol20^0.5·1.5, 시장 갭 뺀 것 등) 중 vol20 이 가장 좋음.
- 원래 갭 규칙 대비 +0.016, 4폴드 모두 상승 (+0.011 +0.033 +0.017 +0.003).

### 왜 ext_range_z 인가
- 의미: 시간외에 크게 출렁이다 도착한 갭은 체결이 적은 시간외 잡음일 가능성이 큼 → 덜 믿음.
- 4폴드 모두 상승 (+0.009 +0.006 +0.002 +0.004, 실험 기준. 팀 기준 경계 후보로는 +0.002 +0.005 +0.001 +0.003), train 이 고른 β 가 4폴드 모두 음수.
- **가중치를 학습 없이 0.2 로 고정해도 4폴드 모두 상승** → 데이터에 맞춘 결과가 아님.
- 6차(더하기)에서 먼저 발견 → 7차(곱하기)에서 재확인 → 10차(미리 정한 조합)에서 다시 1위.
- gap_z 와 순위상관 0.00 (겹침 없음).
- 한계: 효과가 작음(+0.005). 우연과 확실히 구분된다고 말하기엔 부족해서 "작지만 일관된 개선"으로 봄.

### 왜 나머지는 뺐나
1. **방향 정보는 갭뿐**: 갭 계열이 아닌 피처의 방향 IC 는 최대 ±0.05 (gap_z 0.30). 갭이 아닌 피처 하나로 만든 규칙은 score 0.00~0.05.
2. **크기 피처는 점수로 안 바뀜**: atr14·vol·실적의 크기 IC 는 0.20~0.29 로 강함. 하지만 상승 대신 급상승으로 한 칸 올려 찍을 때, 맞으면(정답 급상승) 벌점 4가 줄고 틀리면(정답 급하락) 벌점 28이 늘어남 → 손실이 이득의 7배. 방향을 모르는 종목을 급등락으로 올리면 손해.
3. **밤사이 정보는 갭에 이미 있음**: 실적·애널리스트 밤사이 피처는 train 이 β=0 을 고름. 실적일 갭 중간값은 평소의 8배.
4. **갭 이후 움직임도 갭이 앎**: 9:00 가격 → 종가의 남은 움직임은 혼자 튄 갭일수록 되돌려짐 (순위상관 −0.09, 4기간 모두 음수). 그러나 규칙 경계가 이미 반영하고 있어서 따로 넣으면 하락.
5. **여러 개를 넣으면 무너짐**: train 안에서는 피처를 늘릴수록 오르지만(3개 조합 +0.03~0.09) 다음 60일에서는 떨어짐(−0.013). 고른 피처가 폴드마다 다르고(시장 5일 수익률은 폴드마다 부호가 바뀜), 진짜 피처로 고른 조합과 섞은 가짜로 고른 조합의 결과가 같은 수준.

### 시도한 결합 방식 (모두 gap_z 규칙 이하)
| 방식 | 4폴드 평균 |
|---|---:|
| LightGBM 다중분류 + B 피처 26개 (+ 급등락 34% 디코딩) | 0.417 |
| 방향 모델 + 크기 모델 2단계 | 0.411 ~ 0.419 |
| gap_z 규칙과 LightGBM 섞기 | 섞을수록 하락 |
| 차례로 추가 (train 내부 검증, 최대 6개) | 0.428 |
| Ridge (gap_z + 75개 × 3형태) | 0.411 |
| LightGBM 회귀 (gap_z 단조 제약 + 75개) | 0.385 |
| 미리 정한 6개를 경제적 근거·부호 고정으로 쌓기 | 0.437 ~ 0.444 (ext_range_z 하나가 최고) |
| 2개 조합 66가지, 3개 조합 220가지 전부 (train 내부 검증으로 고름) | 0.438 / 0.425 |
| 규칙 모양 바꾸기 (비대칭 경계, 촘촘한 경계, 최근 기간, 부트스트랩, 구간 표) | 0.433 ~ 0.442, 일관된 개선 없음 |
