# 그림 설명 페이지

이 페이지 하나만 봐도 지금까지 한 일을 이해할 수 있게 만든 그림 설명입니다. 금융을 처음 접하는 팀원 기준이고,
두 worklog(데이터 분리·폴드·누수 검사, EDA)의 내용과 팀원이 물어볼 만한 질문을 담았습니다.

## 여는 방법

| 방법 | 어떻게 | 누가 |
|---|---|---|
| 온라인 페이지 | https://claude.ai/artifact/XRN3c3LHtuXE6mAXvepUfg 을 브라우저에서 열기 | 작성자(남재은)와 공유받은 사람만. 처음 보는 사람은 접근 권한을 요청하거나, 작성자가 페이지 오른쪽 위 **Share** 메뉴에서 공유해야 함 |
| 저장소 사본 | [overnight_gap.html](overnight_gap.html) 을 내려받아 브라우저로 열기 (VS Code 탐색기에서 우클릭 → "Reveal in File Explorer" 후 더블클릭) | 저장소를 받은 누구나. 인터넷이 없으면 글꼴만 기본 글꼴로 바뀜 |

GitHub 웹에서 `.html` 파일을 누르면 코드만 보입니다. 그림으로 보려면 내려받아 브라우저로 열어야 합니다.
