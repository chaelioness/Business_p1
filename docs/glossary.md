## A. 주식 시장의 기본

<a id="stock"></a>
### 주식, 종목, 티커
**주식**은 회사 소유권을 잘게 나눈 조각입니다. 거래소에서 사고팔고, 사려는 사람이 많으면 값이 오르고 팔려는 사람이 많으면 내립니다.
**종목**은 거래되는 주식 하나하나를 말합니다. **티커**는 종목의 약칭입니다(애플 AAPL, AMD AMD, 코카콜라 KO).
이 과제는 미국 대형주 50종목을 다룹니다.

<a id="trading-day"></a>
### 거래일
주식 시장이 열리는 날입니다. 주말과 공휴일(미국 기준)에는 열리지 않습니다. 1년은 약 252거래일입니다.
과제에서 "20일"이라고 하면 보통 **20거래일**(달력으로 약 한 달)을 뜻합니다.

<a id="regular-session"></a>
### 정규장, 개장, 마감
미국 주식 시장의 정식 거래 시간은 뉴욕 시각(ET) **09:30 ~ 16:00** 입니다. 이 시간을 **정규장**이라 부릅니다.
09:30 에 시작하는 것을 **개장**, 16:00 에 끝나는 것을 **마감**이라고 합니다.
과제는 "대상일 개장 직전(09:30)까지 아는 정보로 그날 마감 가격을 맞히는" 문제입니다.

<a id="extended-hours"></a>
### 시간외 거래 (pre / post 세션)
정규장 밖에서도 일부 거래가 이루어집니다.

| 이름 | 시간 (ET) | 데이터 표기 |
|---|---|---|
| 프리마켓 (장 전) | 04:00 ~ 09:30 | `session == "pre"` |
| 애프터마켓 (장 후) | 16:00 ~ 20:00 | `session == "post"` |

참여자가 적어 가격이 덜 정확하지만, **밤사이 나온 소식(실적 발표, 해외 시장 움직임)이 가장 먼저 반영되는 곳**입니다.
그래서 이 과제에서 가장 중요한 정보원입니다 ([보고서 §3](worklog/2026-10-01_EDA_금융데이터_탐색.md#s3)).

<a id="base-target"></a>
### 기준일과 대상일
- **기준일 (B, `day.date`)**: 우리가 "오늘"이라고 부르는 날
- **대상일 (T, `day.target`)**: 그다음 거래일. 이날의 등락을 맞힘

금요일이 기준일이면 대상일은 월요일입니다. 주말 동안 나온 뉴스도 전부 쓸 수 있습니다.

## B. 가격 데이터

<a id="ohlc"></a>
### 시가·고가·저가·종가 (OHLC)
하루(또는 한 시간) 동안의 가격을 숫자 네 개로 요약한 것입니다.

| | 영어 | 뜻 |
|---|---|---|
| 시가 | Open | 구간의 첫 거래 가격 (하루라면 09:30 가격) |
| 고가 | High | 구간 중 가장 높은 가격 |
| 저가 | Low | 구간 중 가장 낮은 가격 |
| 종가 | Close | 구간의 마지막 거래 가격 (하루라면 16:00 가격) |

**전일 종가**는 바로 전 거래일의 종가입니다. 과제의 정답은 "대상일 종가가 전일 종가보다 몇 % 변했나"로 정해집니다.

<a id="bar"></a>
### 봉 (일봉, 시간봉)
일정 시간 동안의 OHLC 와 거래량을 묶은 한 줄을 **봉**이라고 합니다. 차트에서 막대 모양으로 그려서 붙은 이름입니다.
**일봉**은 하루 단위(`daily` 표), **시간봉**은 1시간 단위(`price` 표) 입니다.

주의할 점: 시간봉의 시각은 **봉이 시작한 시각**입니다. 09:30 봉은 09:30~10:30 구간이라 10:30 이 되어야 값이 확정됩니다.
그래서 09:00 프리마켓 봉(09:00~09:30)도 09:30 에야 닫히므로, 09:30 에 예측할 때는 쓸 수 없습니다.

<a id="return"></a>
### 수익률 (등락률)
가격이 몇 % 변했는지입니다.

```
수익률 = (오늘 종가 / 어제 종가 − 1) × 100 (%)
```

100달러가 102달러가 되면 +2%, 97달러가 되면 −3% 입니다.
가격이 아니라 비율로 보기 때문에 비싼 주식과 싼 주식을 같은 잣대로 비교할 수 있습니다.

| 이름 | 계산 | 무엇을 보나 |
|---|---|---|
| 일간 수익률 | 종가 / 전일 종가 | 하루 동안의 움직임 (과제 정답) |
| 5일 / 20일 수익률 | 종가 / 5·20거래일 전 종가 | 최근 1주 / 1개월 흐름 |
| 장중 수익률 | 종가 / 시가 | 개장 후 마감까지의 움직임 |

<a id="bp"></a>
### bp (베이시스 포인트)
0.01% 를 1bp 라고 부릅니다. 10bp = 0.1%. 아주 작은 차이를 말할 때 씁니다.

<a id="gap"></a>
### 갭 (gap)
전일 종가와 다음 날 가격 사이의 **건너뛴 폭**입니다. 밤사이 소식이 나오면 다음 날 시가가 전일 종가와 다른 곳에서 시작합니다.

```
시가 갭 = (대상일 시가 / 전일 종가 − 1) × 100
```

이 과제에서는 09:30 에 시가를 아직 모르므로, 그 대신 **개장 전 마지막 시간외 가격**으로 갭을 미리 잽니다.
EDA 에서 정의한 갭들은 아래와 같습니다.

| 이름 | 계산 | 비고 |
|---|---|---|
| `ovn_gap` (overnight gap) | 전일 종가 → 개장 전 마지막 시간외 가격 | **가장 강한 신호** |
| `pre_move` | 당일 프리마켓 첫 봉 → 마지막 봉 | 기존 기준선이 쓰던 정의 |
| `post_ret` | 전일 종가 → 전일 애프터마켓 마지막 가격 | |
| `mkt_gap` | 50종목 `ovn_gap` 의 평균 | 시장 전체가 밤사이 얼마나 움직였나 |
| `rel_gap` | `ovn_gap − mkt_gap` | 그 종목만의 움직임 |

<a id="volume"></a>
### 거래량, 거래대금
**거래량**은 그 구간에 사고팔린 주식 수, **거래대금**은 거래량 × 가격(달러 금액)입니다.
거래량이 평소보다 많다는 것은 관심이 몰렸다는 뜻이고, 큰 움직임이 함께 오는 경우가 많습니다.
이 데이터에서는 **시간외 봉의 거래량이 기록되어 있지 않습니다** (거의 전부 0).

<a id="split"></a>
### 액면분할
주식 1주를 여러 주로 쪼개는 것입니다(1주 → 2주). 가격이 절반이 되지만 가치는 그대로입니다.
데이터가 이를 반영하지 않으면 −50% 폭락처럼 보이는 오류가 생겨서 데이터 감사 때 확인합니다. 이 데이터에는 그런 흔적이 없었습니다.

## C. 위험과 변동성

<a id="volatility"></a>
### 변동성, 표준편차 (σ)
**변동성**은 가격이 얼마나 출렁이는지를 나타냅니다. 보통 최근 N일 수익률의 **표준편차**로 잽니다.
표준편차는 값들이 평균에서 평균적으로 얼마나 떨어져 있는지이고, 그리스 문자 **σ (시그마)** 로 씁니다.

- `vol20` = 최근 20거래일 일간 수익률의 표준편차
- 코카콜라처럼 안정적인 종목은 σ ≈ 1%, 반도체 종목은 σ ≈ 3~4%

"±2.5% 가 1.6σ 사건" 이라는 말은, 그 종목이 하루에 보통 움직이는 폭의 1.6배라는 뜻입니다.
안정적인 종목에게 2.5% 는 드문 큰 움직임이지만 반도체 종목에게는 흔한 하루입니다.

<a id="atr"></a>
### ATR (Average True Range), 고저폭
**고저폭**은 하루 동안의 (고가 − 저가) / 전일 종가 입니다. 하루 안에서 얼마나 크게 흔들렸나를 봅니다.
**ATR** 은 고저폭과 비슷하되 밤사이 갭까지 포함한 "실제 범위"를 14일 평균한 것입니다. 변동성을 재는 또 다른 방법입니다.

<a id="vol-clustering"></a>
### 변동성 군집 (volatility clustering)
**크게 움직인 날 다음에는 또 크게 움직이기 쉽고, 조용한 날 다음에는 또 조용하기 쉬운** 현상입니다.
방향(오를지 내릴지)은 이어지지 않지만 크기(얼마나 움직일지)는 이어집니다.
금융 데이터에서 가장 잘 알려진 규칙성 중 하나이고, 이 과제에서 "급등락이 올지"를 예측하는 근거가 됩니다.

<a id="normal-dist"></a>
### 정규분포, 두꺼운 꼬리, 첨도, QQ plot
**정규분포**는 평균 근처에 많고 양쪽으로 갈수록 빠르게 줄어드는 종 모양 분포입니다. 평균에서 3σ 넘게 떨어진 값은 0.27% 밖에 안 나옵니다.

실제 주식 수익률은 **꼬리가 두껍습니다**. 극단적인 날이 정규분포가 예상하는 것보다 훨씬 자주 옵니다.
이 데이터에서는 3σ 넘는 날이 정규분포의 6.8배였습니다.

- **첨도(kurtosis)**: 꼬리가 얼마나 두꺼운지를 나타내는 숫자. 정규분포는 0, 이 데이터는 16.7
- **QQ plot**: 실제 분포와 정규분포를 비교하는 그림. 점이 대각선에 붙으면 정규분포, 양 끝이 휘면 꼬리가 두꺼움

## D. 기술적 지표

과거 가격과 거래량만으로 계산하는 지표들입니다. 투자자들이 많이 보지만, 이 과제의 EDA 에서는 방향 예측력이 거의 없었습니다 ([보고서 §4](worklog/2026-10-01_EDA_금융데이터_탐색.md#s4)).

<a id="momentum"></a>
### 모멘텀과 반전
- **모멘텀**: 오르던 것이 계속 오르고 내리던 것이 계속 내린다는 가설
- **반전(mean reversion)**: 많이 오른 것은 되돌아 내리고 많이 내린 것은 되돌아 오른다는 가설

둘 다 기간과 시장 상황에 따라 맞기도 하고 틀리기도 합니다. EDA 에서는 반기마다 어느 쪽이 맞는지 바뀌었습니다.

<a id="ma"></a>
### 이동평균 (MA), 이동평균 괴리
**이동평균**은 최근 N일 종가의 평균입니다(MA20 = 최근 20일 평균). 가격의 대략적인 흐름을 보여 줍니다.
**괴리**는 현재 가격이 이동평균에서 몇 % 떨어져 있는지입니다. +10% 면 평소보다 많이 올라 있다는 뜻입니다.

<a id="rsi"></a>
### RSI (상대강도지수)
최근 14일 동안 오른 폭과 내린 폭의 비율을 0~100 으로 나타낸 값입니다.
70 이상이면 "많이 올랐다(과매수)", 30 이하면 "많이 내렸다(과매도)"로 해석하는 것이 관례입니다.

<a id="dist-hi"></a>
### 20일 고점 대비
현재 가격이 최근 20일 중 가장 높았던 가격보다 몇 % 아래에 있는지입니다. 0 이면 지금이 최고점이고, −20% 면 고점에서 많이 떨어진 상태입니다.

## E. 기업 이벤트

<a id="earnings"></a>
### 실적 발표, 어닝 시즌
상장 회사는 **분기(3개월)마다** 매출과 이익을 공개합니다. 이것이 **실적 발표**입니다.
주로 개장 전(06:00~08:00) 이나 마감 직후(16:00) 에 발표해서, 반응은 시간외 거래와 다음 날 갭으로 나타납니다.
많은 회사가 비슷한 시기에 발표해서 그 기간을 **어닝 시즌**이라 부릅니다. 1·4·7·10월 중순~하순이 몰리는 시기이고,
**이 과제의 평가 기간(10월)이 바로 어닝 시즌**입니다.

<a id="eps"></a>
### EPS, 컨센서스, 서프라이즈
- **EPS (주당순이익)**: 회사 이익을 주식 수로 나눈 값. 실적의 대표 숫자
- **컨센서스 (`eps_estimate`)**: 애널리스트들이 발표 전에 예상한 EPS 의 평균
- **서프라이즈 (`surprise_pct`)**: 실제 EPS 가 예상과 몇 % 다른지. +면 "예상 상회", −면 "예상 미달"

주가는 실적이 좋은지 나쁜지보다 **예상보다 좋은지 나쁜지**에 반응합니다. 다만 회사들이 예상을 넘기기 쉽게 관리하는 경향이 있어서,
이 데이터에서도 87% 가 "상회"였습니다. 그래서 "상회했다"는 사실만으로는 정보가 적습니다.

<a id="analyst"></a>
### 애널리스트, 투자의견, 목표주가
**애널리스트**는 증권사에서 기업을 분석해 보고서를 내는 사람입니다. 보고서에는 두 가지가 들어 있습니다.

- **투자의견 (`action`)**: 매수·보유·매도 같은 등급. `up` 은 등급 상향, `down` 은 하향, `init` 은 분석을 새로 시작, `main`·`reit` 은 유지
- **목표주가 (`target_current`)**: 앞으로 이 가격까지 갈 것이라는 예상치. `Raises` 는 상향, `Lowers` 는 하향

목표주가 조정은 이미 주가가 움직인 뒤 따라서 나오는 경우가 많습니다.

## F. 시장 전체

<a id="market-return"></a>
### 시장 수익률 (등가중)
여기서 "시장"은 50종목 수익률의 단순 평균입니다(**등가중**, 모든 종목을 같은 비중으로).
S&P500 같은 실제 지수는 회사 크기에 비례해 비중을 주지만, 이 과제에는 지수 데이터가 없어서 직접 만들었습니다.

<a id="market-factor"></a>
### 시장 요인, 개별 요인
한 종목의 움직임은 두 부분으로 나눠 볼 수 있습니다.

- **시장 요인**: 시장 전체가 같이 움직이는 부분 (금리 발표, 관세 뉴스처럼 모든 종목에 영향)
- **개별 요인**: 그 회사에만 해당하는 부분 (실적, 신제품, 소송)

EDA 에서는 종목 움직임의 약 23~27% 가 시장 요인이었습니다. 나머지 대부분은 개별 요인입니다.

<a id="cross-section"></a>
### 횡단면, 횡단면 분산
**횡단면**은 "같은 날 여러 종목을 나란히 놓고 비교하는 것"입니다(반대말은 한 종목을 시간 순서로 보는 **시계열**).
**횡단면 분산**은 같은 날 종목들의 수익률이 서로 얼마나 다른지입니다. 크면 종목마다 제각각 움직인 날입니다.

<a id="sector"></a>
### 섹터, 방어주
**섹터**는 비슷한 사업을 하는 회사들의 묶음입니다(반도체, 금융, 에너지, 헬스케어). 같은 섹터는 같이 움직이는 경향이 있습니다.
**방어주**는 경기와 상관없이 수요가 꾸준한 회사(음료, 식품, 생활용품, 통신)로, 변동성이 낮습니다. 이 과제에서는 KO·PM·JNJ·WMT 등이 해당합니다.

<a id="regime"></a>
### 국면 (regime)
시장의 분위기가 일정 기간 유지되는 상태입니다. "조용한 국면"에는 급등락이 드물고, "불안한 국면"에는 자주 옵니다.
EDA 에서 월별 급등락 비율이 7% ~ 30% 로 4배 넘게 변한 것이 국면 차이입니다.

<a id="tariff-rally"></a>
### 2025-04-09 관세 유예 랠리
2025년 4월 초 미국의 대규모 관세 발표로 시장이 급락했다가, 4월 9일 관세 시행 유예 발표로 하루 만에 크게 반등한 사건입니다.
50종목 중 다수가 이날 +10% 넘게 올라 데이터에 이상치처럼 보이지만 실제 사건입니다. **랠리**는 짧은 기간의 강한 상승을 말합니다.

## G. 통계 도구

<a id="correlation"></a>
### 상관계수, Spearman 상관
두 값이 같이 움직이는 정도를 −1 ~ +1 로 나타낸 것입니다. +1 이면 완전히 같이, 0 이면 무관, −1 이면 정반대로 움직입니다.

- **Pearson 상관**: 값 자체로 계산. 극단값 하나에 크게 흔들림
- **Spearman 상관**: 값을 순위로 바꾼 뒤 계산. 극단값에 강해서 꼬리가 두꺼운 주식 데이터에 적합

<a id="ic"></a>
### IC (Information Coefficient, 정보계수)
투자 분야에서 피처의 예측력을 재는 표준 방법입니다. **하루마다** 50종목에 대해 "피처 값"과 "다음 날 수익률"의 Spearman 상관을 구하고,
그것을 모든 날에 걸쳐 평균합니다. 이런 방식을 **Fama-MacBeth 방식**이라고 부릅니다.

- 하루 안에서 비교하기 때문에, 시장 전체가 크게 움직인 며칠에 결과가 끌려가지 않음
- 주식 예측에서 IC 0.02~0.05 면 쓸 만하고, 0.1 이상이면 매우 강한 편
- 이 과제의 `ovn_gap` 은 IC 0.30 으로 매우 강함 (개장 전 정보라서 가능한 값)

**방향 IC** 는 다음 날 수익률과의 IC, **크기 IC** 는 다음 날 |수익률|(절댓값)과의 IC 입니다.

<a id="t-stat"></a>
### t값, 유의성
"이 결과가 우연이 아닐 가능성"을 나타내는 숫자입니다. 여기서는 `IC 평균 / IC 표준편차 × √(일수)` 로 계산했습니다.
대략 **|t| > 2 면 우연이라 보기 어렵고**, |t| < 2 면 우연일 수 있다고 봅니다. t = 26 은 우연일 가능성이 사실상 없다는 뜻입니다.

<a id="auc"></a>
### AUC
어떤 피처가 두 그룹(예: 급등락한 날 vs 아닌 날)을 얼마나 잘 가르는지를 0.5 ~ 1 로 나타냅니다.
무작위로 한 쌍을 골랐을 때 피처 값이 급등락 쪽에서 더 클 확률입니다. **0.5 면 구별 못 함, 0.7 이면 꽤 구별함, 1 이면 완벽**.

<a id="r2"></a>
### R² (결정계수)
한 값이 다른 값의 변화를 몇 % 설명하는지입니다. R² = 0.76 이면 "변화의 76% 를 설명한다"는 뜻입니다.

<a id="quantile"></a>
### 분위, 10분위
값을 크기 순으로 줄 세워 같은 개수로 나눈 것입니다. 10분위면 10개 그룹으로, 1분위가 가장 작은 10%, 10분위가 가장 큰 10% 입니다.
"변동성 10분위별 급등락 확률"은 변동성이 낮은 그룹부터 높은 그룹까지 급등락 확률이 어떻게 변하는지 보는 것입니다.

<a id="autocorr"></a>
### 자기상관
오늘 값과 며칠 전 값 사이의 상관입니다. **lag 1** 은 하루 전과의 상관입니다.
수익률의 자기상관이 0 에 가깝다는 것은 "어제 올랐다고 오늘 오를지 알 수 없다"는 뜻입니다.

<a id="residual"></a>
### 잔차, 통제, 부분상관
- **잔차**: 어떤 값에서 다른 변수로 설명되는 부분을 뺀 나머지
- **통제한다**: 이미 아는 변수의 영향을 빼고 본다는 뜻
- **부분상관**: 두 값에서 각각 통제 변수의 영향을 뺀 뒤 구한 상관

"갭을 통제한 뒤 뉴스의 IC" 는 "갭이 이미 알려 주는 것을 빼고도 뉴스가 새로 알려 주는 것이 있나"를 보는 것입니다.
이것이 0 이면 그 피처는 이미 가진 정보를 반복할 뿐입니다.

<a id="ks"></a>
### KS 검정
두 그룹의 분포가 같은지 비교하는 검정입니다. KS 값이 클수록(0~1) 두 분포가 다릅니다. unseen 종목이 학습 종목과 얼마나 다른지 볼 때 썼습니다.

<a id="gdelt"></a>
### 논조 (tone), GDELT
뉴스 데이터의 `tone` 은 기사에 긍정 단어와 부정 단어가 얼마나 있는지로 계산한 점수입니다. 전 세계 뉴스를 모으는 GDELT 프로젝트와 같은 방식으로 보입니다.
단어 목록 기반이라 "실적이 예상보다 덜 나빴다" 같은 금융 맥락을 이해하지 못합니다.

## H. 검증과 누수

<a id="leakage"></a>
### 누수 (leakage), `known_at`, cutoff
**누수**는 예측 시점에는 알 수 없었던 정보를 모델이 쓰는 것입니다. 누수가 있으면 연습 점수는 높지만 실제 채점에서 무너집니다.

- **`known_at`**: 그 값을 실제로 알 수 있게 된 시각. 데이터를 자르는 기준
- **cutoff**: 예측 시점. 이 과제에서는 대상일 09:30. `known_at < cutoff` 인 데이터만 쓸 수 있음

자세한 규칙은 [과제 개요 §3](project_overview.md#3-누수-규칙-known_at) 과 [worklog §5](worklog/2026-10-01_2019_데이터분리_폴드_누수검사_기준선.md#5-누수-검사-미래-정보를-쓰면-에러가-남) 에 있습니다.

<a id="fold"></a>
### 폴드, 교차검증 (CV), walk-forward
**폴드**는 "학습 기간 + 검증 기간" 한 세트입니다. 기간을 바꿔 가며 여러 번 시험해서 운에 의한 점수를 걸러내는 것을 **교차검증(CV)** 이라고 합니다.
주식 데이터는 무작위로 섞으면 미래로 과거를 학습하게 되므로, 항상 **과거로 학습하고 그 뒤로 검증**합니다(walk-forward).
팀 폴드 4개의 날짜는 [worklog §4](worklog/2026-10-01_2019_데이터분리_폴드_누수검사_기준선.md#4-폴드-연습-시험-4번) 에 있습니다.

<a id="embargo"></a>
### embargo (비워 두는 기간)
학습 기간과 검증 기간 사이를 일부러 비워 두는 것입니다. 실제 평가도 데이터 끝(9/14)과 채점 시작(10/1) 사이가 12거래일 비어 있어서, 연습도 똑같이 12거래일을 비웁니다.

<a id="holdout"></a>
### 홀드아웃
모든 결정을 내린 뒤 **마지막에 딱 한 번만** 점수를 보는 숨겨 둔 기간입니다(2026-06-01 이후). 미리 보면 시험 문제를 보고 공부한 셈이 됩니다.

<a id="in-sample"></a>
### in-sample, out-of-sample, 과적합
- **in-sample**: 규칙을 정할 때 쓴 데이터로 잰 점수. 실제보다 좋게 나오기 쉬움
- **out-of-sample**: 규칙을 정할 때 안 쓴 데이터로 잰 점수. 실제 성능에 가까움
- **과적합**: 학습 데이터의 우연한 패턴까지 외워서, 새 데이터에서 성능이 떨어지는 것

EDA 의 임계값 탐색은 in-sample 이고, §8 의 폴드 CV 가 out-of-sample 확인입니다.

<a id="unseen"></a>
### seen / unseen 종목
평가 종목 20개 중 10개는 우리가 받은 적 없는 **처음 보는 종목(unseen)** 입니다.
이를 흉내 내려고 50종목 중 10개(`BA, BKNG, CVS, GLW, NFLX, PFE, QCOM, RTX, TMO, WELL`)를 학습에서 빼고 따로 점수를 봅니다.

<a id="panel"></a>
### 패널
(종목, 날짜) 한 쌍이 한 행인 표입니다. EDA 의 패널은 50종목 × 376 대상일 = 18,850행이고, 각 행에 그날 쓸 수 있는 피처와 정답이 들어 있습니다.

<a id="baseline"></a>
### 기준선 (baseline)
아주 단순한 규칙으로 낸 점수입니다. 모델이 이것보다 낫지 않으면 아무것도 배우지 못한 것입니다.

## I. 이 과제의 점수

<a id="label"></a>
### label (5등급)

| label | 이름 | 대상일 수익률 |
|---|---|---|
| 0 | 급하락 | −2.5% 미만 |
| 1 | 하락 | −2.5% ~ −0.6% |
| 2 | 보합 | −0.6% ~ +0.6% |
| 3 | 상승 | +0.6% ~ +2.5% |
| 4 | 급상승 | +2.5% 초과 |

**급등락**은 급하락(0)과 급상승(4)을 합쳐 부르는 말입니다.

<a id="confusion"></a>
### 혼동행렬
행은 정답, 열은 예측으로 놓고 각 칸에 건수를 센 5×5 표입니다. 대각선이 맞힌 것이고, 대각선에서 멀수록 크게 틀린 것입니다.

<a id="score"></a>
### score (가중 벌점 점수)

```
score = 1 − (실제 벌점 합) / (무작위로 찍었을 때 기대 벌점 합)
벌점 w = (정답 − 예측)² × (|정답 − 2|)²
```

- 0 이면 무작위 수준, 1 이면 전부 맞힘, 음수면 무작위보다 못함
- **정답이 보합(2)인 날은 무엇을 찍어도 벌점 0** → 점수는 급등락 날에서 대부분 결정됨
- 정답이 급등락인데 반대로 찍으면 벌점 64 로 가장 큼

예시: 정답이 급상승(4)일 때 상승(3)을 찍으면 벌점 4, 정답이 상승(3)일 때 급상승(4)을 찍으면 벌점 1.
이 비대칭 때문에 애매하면 센 쪽으로 찍는 것이 유리합니다. 계산 예시는 [과제 개요 §6](project_overview.md#6-점수) 에 있습니다.

<a id="recall-prec"></a>
### big_recall, big_prec
- **big_recall (포착률)**: 실제 급등락 중 급등락으로 맞힌 비율. "놓치지 않았나"
- **big_prec (적중률)**: 급등락이라고 찍은 것 중 실제 급등락이었던 비율. "남발하지 않았나"

하나를 올리면 다른 하나가 내려가는 관계라 같이 봐야 합니다.

<a id="aggressiveness"></a>
### 공격성, 임계값
**임계값**은 "갭이 몇 % 넘으면 급등락으로 찍을지" 같은 경계입니다. 임계값을 낮추면 급등락을 더 자주 찍습니다(공격적).
EDA 에서는 공격성 계수 k 를 두고 `예측 = label_of(k × 갭)` 으로 바꿔 가며 점수가 어떻게 변하는지 봤습니다.
k = 2 면 갭이 1.25% 만 넘어도 2.5% 로 간주해 급상승으로 찍습니다.
