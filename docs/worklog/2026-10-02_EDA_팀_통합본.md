## 2. 검증 방식이 두 개다 — 가장 먼저 정리할 것

| | A 방식 (`lab/folds.json`, main 에 있음) | B 방식 (`work/common/folds.py`, minyoung-eda) |
|---|---|---|
| 구조 | 폴드 4개 (walk-forward), val 각 60거래일 | val 한 구간 (holdout) |
| val 기간 (대상일) | 2025-06-13 ~ 2026-05-28 사이 4구간 | 2026-03-02 ~ 2026-05-29 (63일) |
| 학습과 val 사이 공백 | 12거래일 | 10거래일 |
| 처음 보는 종목 | 10개 고정 제외 (BA BKNG CVS GLW NFLX PFE QCOM RTX TMO WELL) | 제외 조합 3개로 별도 실험 |
| 주 지표 | 폴드별 score 평균 | val 전체 score + 월별 |

**문제: EDA 구간과 A 의 폴드 1~3 검증 기간이 겹칩니다.** 세 사람 모두 대상일 ~2026-02-12까지 데이터를 보고 피처를 골랐는데,
A 의 폴드 1~3 검증 기간(2025-06 ~ 2026-03)이 이 안에 들어 있습니다. 엄밀히는 폴드 1~3 점수가 부풀려졌을 수 있습니다 (B 가 REPORT 에서 먼저 지적).

이 영향을 받지 않는 점수는 **2026-03 이후 검증**뿐입니다. 거기서는 두 방식이 거의 같은 값을 냈습니다.

| 2026-03 ~ 05 검증, 갭 하나짜리 규칙 | score |
|---|---|
| A fold4 `ovn_gap` 규칙 (val 2026-03-04 ~ 05-28, 공백 12일) | **0.511** |
| B `gap_z` 규칙 (val 2026-03-02 ~ 05-29, 공백 10일) | **0.482** |
| A fold4 `pre_move` 규칙 (기존 기준선 정의) | 0.306 |
| B `pre_move` 규칙 | 0.34 |

→ "전일 종가 기준 갭" 의 효과는 오염되지 않은 기간에서도 두 사람이 따로 확인했습니다. 다만 폴드 1~3 을 포함한 A 의 평균 0.433 은 낙관적일 수 있습니다.
어떻게 통일할지는 [§9](#9-회의에서-정할-것) 1번 안건입니다.

## 4. 정답(label)의 성질

세 사람의 수치가 같습니다 (같은 기간, 같은 `label_of`).

- label 분포: 급하락 6.6 / 하락 23.3 / 보합 34.9 / 상승 28.2 / 급상승 7.0%. 급등락 13.6%.
- 꼬리가 두꺼움: 초과 첨도 16.7, 3σ 넘는 날이 정규분포의 6.8배 (A, B).
- 크기는 이어지고 방향은 안 이어짐: |수익률| 자기상관 lag1 0.118~0.119, 수익률 lag1 −0.026 (A, B). 급등락 다음 날 급등락 약 25% (평소 10~14%).
- 종목별 급등락 2.7% (JNJ·KO) ~ 41.9% (INTC), 종목 변동성과 상관 0.98 (A, B).
- 시장이 종목 움직임의 약 23~27% 를 설명 (A, B). 2025-04-04 는 50종목 전부 급등락 (B).
- **시기 변화:** 2025-04 관세 충격 30%, 2025-09 8.7%, 2026-02 30% (부분월). B·C 모두 "단조 증가가 아니라 높은 시기와 낮은 시기가 교차"로 해석.
  **train 13.6% vs 2026-03~05 val 19.3%** (B) → 찍는 경계를 어느 비율에 맞출지가 안건 ([§9](#9-회의에서-정할-것)).
- 경계 주의 (C): `label_of` 는 `right=False` 라 정확히 +2.5% 는 급상승(4), +0.6% 는 상승(3). 슬라이드의 "초과" 표기보다 코드가 우선.

## 5. 방향 — 시간외 갭

**정의는 A·B 가 같습니다.**

```
gap   = (cutoff 전 마지막 시간외 봉 종가 / 기준일 종가 − 1) × 100     # A: ovn_gap, B: gap
gap_z = gap / vol20                                                  # B 의 주 피처, A 의 ovn_gap_z
```

| 피처 | A 일별 IC (t) | B 일별 IC (t) |
|---|---|---|
| 전일 종가 기준 갭 (`ovn_gap` / `gap`) | 0.299 (26.3) | 0.299 (26.3) |
| 갭 ÷ 변동성 (`ovn_gap_z` / `gap_z`) | 0.283 (26.6) | 0.283 (26.6) |
| 시장 대비 갭 (`rel_gap` / `gap_rel_z`) | 0.299 | 0.295 (26.0) |
| 프리마켓 안 등락 (`pre_move`, 기존 기준선) | 0.151 (14.4) | 0.184 (18.3) |
| 애프터마켓만 (`post_ret`) | 0.091 (8.6) | 0.092 (8.7) |

`pre_move` 수치 차이(0.151 vs 0.184)는 프리마켓 "첫 봉" 정의가 조금 달라서로 보입니다. 나머지는 사실상 같은 값입니다.

**B 가 더한 것**
- 날짜별 IC 20일 이동평균이 0.14~0.43, 18개월 동안 한 번도 0 아래로 내려가지 않음.
- 성공률: gap_z 가 ±2 를 넘으면 83~91% 맞음, 전체의 65% 인 \|gap_z\|<0.3 인 날은 56% (동전 수준).
- 실제 예: NEM 2025-10-23 장 마감 후 실적 → gap −6.73%, gap_z −1.83 → 다음 날 −6.22% (급하락).

**A 가 더한 것**
- 시가 갭을 08:00 시간외 가격이 R² 0.76 으로 미리 보여 줌, 하루 분산의 약 30% 가 개장 전에 보임.
- 시장 전체 갭은 장중에 되돌림 (시장 갭 하위 분위 → 장중 +0.23%), 개별 갭은 유지 → `mkt_gap`/`rel_gap` 분리 근거.
- 규칙 위반 검토: 과제 PDF 8쪽 "대상일 개장 전 시간외 거래" 명시, 데이터 시각 오류 없음 ([A §8 검토](2026-10-01_EDA_금융데이터_탐색.md#점수가-높은데-규칙-위반은-아닌가-검토)).

## 7. 점수식과 찍는 규칙(디코딩)

세 사람이 같은 함수를 썼고, 공통으로 **"가장 확률 높은 등급(argmax)을 그대로 찍으면 손해"** 라는 결과가 나왔습니다.

| | 실험 | 결과 |
|---|---|---|
| A | 갭 규칙의 공격성 k, 경계 a·b 탐색 (EDA 구간, in-sample) | 급등락을 실제(13.6%)보다 많이(약 34%) 찍을 때 최고, 보합은 거의 안 찍는 쪽이 유리 |
| B | LightGBM argmax vs 분포 맞춤 디코딩 (val 2026-03~05) | argmax 는 보합 42% → 0.420, **분포 맞춤(기대 등급을 train 비율 분위로 자름) 0.478 (+0.058)**, 3개월 모두 상승 |
| B | 클래스 가중 (빈도 역수) | 0.459, 급등락 과다 (big_prec 0.26) |
| B·C | 기대 벌점 최소 디코딩 (argmin Σ p·w) | B 0.421, C 개선 없음 → 보합으로 쏠림 |

**정리:** 기대 벌점 최소화는 점수 분모(무작위 기대 벌점)가 예측 분포에 따라 변하는 걸 반영하지 못해 보합으로 쏠립니다 (C 가 이론적으로, B 가 실험으로 확인).
"보합 정답 행은 벌점 0 이라 보합 예측이 점수에 영향 없다"는 말은 분모 때문에 정확하지 않습니다 (C 지적, A 보고서 §6 과 같은 내용).
분포 맞춤이나 공격성 튜닝처럼 **예측 등급 비율을 직접 정하는 방식**이 효과가 있었습니다. 어느 비율에 맞출지가 안건입니다.
