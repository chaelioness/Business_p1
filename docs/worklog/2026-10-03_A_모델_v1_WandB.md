### 2.2 LightGBM (B 피처 26개 `B_FEATURES_V1`) — 디코딩 비교

모델은 하나 (폴드마다 같은 학습), 확률을 등급으로 바꾸는 방법만 다름.
B 기본 파라미터 (num_leaves 15, min_data_in_leaf 300, lr 0.05), 반복 수는 학습 구간 마지막 40일 조기 종료로 정함 (45~70회).

| run | 디코딩 | **fold4** | 처음 보는 종목 | 4폴드 평균 | 3월 | 4월 | 5월 |
|---|---|---|---|---|---|---|---|
| [lgb_v1_argmax](https://wandb.ai/BI_finance_project/finance-direction/runs/mshbzaqk) | 가장 큰 확률 | 0.433 | 0.351 | 0.361 | 0.375 | 0.424 | 0.480 |
| [lgb_v1_match_train](https://wandb.ai/BI_finance_project/finance-direction/runs/fikqck9x) | 분포 맞춤 (train 비율) | 0.478 | 0.378 | 0.408 | 0.444 | 0.458 | 0.507 |
| [lgb_v1_match_recent](https://wandb.ai/BI_finance_project/finance-direction/runs/tr5hcgd8) | 분포 맞춤 (train 마지막 60일 비율) | 0.480 | 0.379 | 0.408 | 0.454 | 0.461 | 0.500 |
| [lgb_v1_aggr](https://wandb.ai/BI_finance_project/finance-direction/runs/djm51u9z) | 공격성 k (급등락 ×k, 보합 ÷k) | **0.495** | 0.416 | 0.413 | 0.461 | 0.493 | 0.506 |

- 디코딩 정의: 기대 등급 e = Σ i·pᵢ 를, 원하는 등급 비율이 되는 e 의 분위로 자름. 분위는 **train 예측**으로만 정함.
- 공격성 k 는 후보 {1, 1.25, 1.5, 2, 2.5, 3} 중 학습 구간 마지막 40일(조기 종료용 구간)에서 score 가 가장 높은 값. 폴드별로 3.0 / 1.5 / 2.0 / 2.5 가 골라짐.
- argmax → 분포 맞춤이 +0.045 (B 의 +0.058 과 같은 방향), 공격성까지 +0.062.
- **그래도 규칙보다 0.020 낮음.** 모든 달에서도 규칙이 높음. B 실험(0.417)과 같은 결론.

### 2.3 C 텍스트 피처 ablation (LightGBM + 공격성 디코딩)

C 의 텍스트 피처를 dev 데이터로 다시 만들어 (`symbol + target` 으로) 붙임. `text_overnight_hours` 는 C 안내대로 모든 그룹에 공통.

| [ablation_struct+news](https://wandb.ai/BI_finance_project/finance-direction/runs/znvudg4l) | + 뉴스 2 | 0.492 | 0.416 | 0.377 | 0.395 | 0.390 | 0.413 |
| [ablation_struct+reddit](https://wandb.ai/BI_finance_project/finance-direction/runs/fcezog6y) | + Reddit 3 | 0.469 | 0.368 | 0.363 | 0.411 | 0.393 | 0.409 |
| [ablation_struct+text_all](https://wandb.ai/BI_finance_project/finance-direction/runs/wkxz2dok) | + 7개 전부 | 0.474 | 0.374 | 0.361 | 0.403 | 0.387 | 0.406 |

판정 (채택 기준):
- 뉴스: fold4 −0.002, 상승 2/4폴드 (fold1·3) → **불채택**. 다만 fold1 이 +0.056 으로 크게 오르고 처음 보는 종목도 +0.008 → 규칙 위에 얹는 형태로 v2 에서 한 번 더 볼 가치.
- Reddit: fold4 −0.025 → **불채택**.
- 7개 전부: fold4 −0.020 → **불채택**.
- ablation 의 디코딩(aggr)은 2.2 에서 fold4 점수를 보고 고른 것임. 그래서 ablation 안의 비교는 공정하지만, 절대 점수는 약간 낙관적일 수 있음.

## 7. v2 실험: LLM 없는 텍스트 + 여러 모델·손실 (같은 날 오후)

코드: `work/a/exp2.py` (피처 표·텍스트), `work/a/models2.py` (모델), `scripts/a_v2.py` (실행). W&B 태그 `v2`, 28개 run (그 밖에 L1 단조 제약 오류·TF-IDF 열 타입 오류로 중간에 멈춘 run 2개).
검증·채점은 위와 같음. 비교 기준은 B 규칙 (fold4 0.515, 4폴드 평균 0.447 / 이 표의 `rule_base` 는 λ 후보가 조금 달라 0.450).

**텍스트 재료 (LLM 없음, 전부 `day.news` 로 꺼내 guard 아래에서 만듦)**
- 장 마감 후 기사 제목 캐시 (`cache/news_titles.parquet`, dev 449일, 210만 행, (url, 종목) 중복 제거)
- 사건 단어 수: 실적·가이던스·애널리스트·소송·M&A·FDA·경영진·호재·악재 단어 목록 (결과 보기 전에 정해 `EVENTS` 에 고정)
- 학습 텍스트 점수: 폴드 train 제목으로만 학습한 TF-IDF(1~2gram) 로지스틱 → `text_big` (급등락일 확률), `text_dir` (급등락이면 위일 확률). train 행 값은 날짜 4구간 교차 적합이라 자기 자신을 외운 값이 아님
- C 텍스트 7개

**모든 모델의 디코딩은 같음:** 연속 점수 s → |s| 분위 후보 중 train score 최대인 경계 a, b (B 규칙과 같은 방식).

| 묶음 | run (fold4 / 처음 보는 종목 / 4폴드 평균) | 판정 |
|---|---|---|
| 기준 | `v2_rule_base` 0.515 / 0.418 / 0.450 | |
| 규칙 × 텍스트로 갭 신뢰도 조절 s = gz·exp(−λx̃ + γ·z(f)) | lex_event, lex_n, 뉴스 수(C): **train 이 γ = 0 을 고름 → 규칙과 같음** / text_big 0.511 / 0.417 / 0.449 | 효과 없음 |
| 규칙 + 급등락 경계만 피처로 이동 | 실적 발표 0.516 / 0.416 / 0.451 (폴드별 +0.002 −0.001 +0.003 +0.001), atr14 0.517 / 0.421 / 0.447, 사건 단어 0.515, 실적 단어 0.514, 뉴스 수 0.515, text_big 0.512 | 기준 미달 (평균 +0.005 못 넘음) |
| 규칙 + 텍스트 방향 더하기 | text_dir, 호재−악재 단어: **train 이 β = 0** → 규칙과 같음 | 효과 없음 |
| 선형 (손실 비교) | Ridge(제곱) 0.504 / 0.373 / 0.433, **Huber 0.507** / 0.399 / 0.436, Huber+텍스트 0.501 / 0.401 / 0.438, 다항 로지스틱 0.500 / 0.383 / 0.429 | 규칙 이하 |
| LightGBM 회귀 (손실 비교, B 26개, gap_z 단조 제약) | L2 0.504 / 0.412 / 0.392, Huber 0.481 / 0.386 / 0.424, L1 0.471 / 0.373 / 0.426 | 규칙 이하 |
| LightGBM 기타 손실 | 순서형(label 회귀) 0.489 / 0.419 / 0.405, **점수식 가중 다항** (급등락 행 ×4, 보합 ×0.25) 0.499 / **0.428** / 0.382 | 규칙 이하 (처음 보는 종목은 가중 다항이 가장 높음) |
| sklearn HistGB (L1) | 0.451 / 0.351 / 0.386 | 규칙 이하 |
