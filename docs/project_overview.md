## 3. 누수 규칙 (`known_at`)

모든 표의 `known_at`은 "그 값을 언제부터 알 수 있었는지". **자르는 기준은 `known_at` 하나뿐.**

| | 일어난 시각 | 알 수 있었던 시각 |
|---|---|---|
| 1시간봉 | 봉의 시작 09:30 | 봉이 닫히는 10:30 |
| 일봉 | 그날 | 16:00 마감 |
| 실적 | 발표 시각 | 같음 |
| Reddit 글·댓글 | 올라온 때 | 올라온 직후 (`created_et`로 자름 — Reddit만 `known_at` 없음) |
| Reddit `score`, `n_comments` | 글이 올라온 때 | 36시간 뒤 → **feature로 쓰지 말 것** |

## 4. 데이터 API

```python
ds = Dataset()
train, test = ds.split("2026-06-01")
day = test[0]
```

| 호출 | 돌려주는 것 |
|---|---|
| `day.date` / `day.target` / `day.cutoff` | 기준일, 예측 대상일, 대상일 09:30 |
| `day.daily(days=20)` | 최근 20거래일 일봉 |
| `day.price(days=1)` | 시간봉 |
| `day.news(["AMD"], days=5)` | 기사 |
| `day.reddit("stocks", "comments")` | 글과 댓글 |

- `days`는 거래일 기준. 구간을 넓혀도 끝은 항상 cutoff
- cutoff까지 들어오는 것: 기준일 장 마감 후 뉴스, 대상일 개장 전 시간외 거래

## 5. 기간 나누기

기준일 앞은 학습, 기준일부터는 평가. **무작위로 섞으면 내일 데이터로 오늘을 학습하게 됨.**

| 방식 | 코드 |
|---|---|

| walk-forward | 기준일을 여러 개 두고 같은 함수를 반복 |

## 6. 점수

```
score = 1 − Σ(w·O) / Σ(w·E)
w[i][j] = (i − j)² × (|i − 2|)²      # i: 정답, j: 예측
O[i][j] = 정답 i, 예측 j인 건수
E[i][j] = (i행 합) × (j열 합) / N     # 무작위 예측 시 기대 혼동행렬
```

가중치 w (행 = 정답, 열 = 예측):

| 정답 \ 예측 | 급하락 | 하락 | 보합 | 상승 | 급상승 |
|---|---|---|---|---|---|
| 급하락 | 0 | 4 | 16 | 36 | 64 |
| 하락 | 1 | 0 | 1 | 4 | 9 |
| 보합 | 0 | 0 | 0 | 0 | 0 |
| 상승 | 9 | 4 | 1 | 0 | 1 |
| 급상승 | 64 | 36 | 16 | 4 | 0 |

- 0점이 우연 수준, 전부 맞히면 1점. 비대칭이라 **하한이 없음**
- 정답이 보합인 날은 뭘 찍어도 벌점 0 → 점수는 사실상 급등락일(약 16%)에서 결정됨
- 슬라이드 예시: Σw·O = 24, Σw·E = 37.6 → score = 0.36

| 전략 | score |
|---|---|
| 전부 보합, 또는 한 등급만 계속 | 0.000 |
| 방향만 맞고 세기는 틀림 | +0.827 |
| 급등락만 잡고 나머지 보합 | +0.896 |
| 급등락을 정반대로 | −1.781 |
| 전부 맞힘 | +1.000 |
