### 4. 실적 표로 채민 LLM 추출 검증

| LLM \ 실적 표 | EPS 상회 | EPS 하회 | 합 |
|---|---:|---:|---:|
| above | **649** | 39 | 688 |
| below | 84 | **61** | 145 |
| in_line | 18 | 3 | 21 |

### 13. 시간외 고가·저가 이상치 (P1)

> ✅ **10/8 결과 ([06 문서](06_배치_실험.md)):** 봉 종가 기준 −0.003, 16시 봉 제외 −0.002 → **이상치를 빼면 오히려 나빠짐. 지금 정의 유지.** 고가·저가의 튀는 값 자체가 "시간외 거래가 불안정했다"는 신호일 수 있음

  - 16시 봉을 뺀 고가·저가

### 5. 상관 피처 묶음 중요도 (P2)

> ✅ **10/8 ([07 문서](07_남은_항목.md)):** 방향 = 갭 묶음 0.76, 크기 = 변동성 묶음 0.25. 갭 피처를 하나씩 섞으면 하락 합 0.18, 묶음으로 섞으면 0.34

- **왜:** A 발표 10장은 gap · gap_z · gap_rel_z 의 SHAP 를 따로 보여 줌. 셋은 같은 정보라 몫을 나눠 가져 각각 작아 보임 (w6-1 p14, p18)
- **어떻게:** A 의 fold4 LightGBM(B 피처 26개)을 다시 만들고 묶음별 SHAP 합 + 묶음 permutation(30회). 묶음: 갭 / 변동성 / 실적 / 애널리스트 / 텍스트
- **기대:** "방향 = 갭 묶음, 크기 = 변동성 묶음"을 더 단단한 근거로

### 6. faithfulness 검사 (P2)

### 11. 확신도가 낮으면 급등락을 덜 찍기 (P2)

- **회의 내용:** 벌점의 51% 가 급등락을 정반대로 찍은 3% 행에서 나오니, 방향이 애매하면 급등락 대신 상승·하락으로 찍자 (재은). LLM 으로 확신도를 받는 방안도 나옴
- **03 문서로 고친 점:** ext_range_z 는 방향 확신도가 아님 (출렁임이 클수록 갭 방향이 더 잘 맞음). 방향 확신도 장치는 아직 없음
- **정반대로 찍은 행의 모습:** 변동성 큰 종목의 평범한 갭이 경계 b 를 겨우 넘어 급상승으로 찍히고 장중에 반대로 감 (03 문서 1절 예시 ②). 아침 정보로 구분하기 어려움
- **어떻게 (실행 전에 고정):** 새 후보는 7번의 갭 신선도 `gap_age_h` 하나만. `s = gz · exp(−λ·x̃ − μ·z)`, μ 는 train 으로만. 장후·장전 방향 일치도(`new_agree3`)는 B 실험에서 이미 빠져서 다시 안 함

### 12. 처음 보는 종목 점수가 낮은 이유 (P2)

> ✅ **10/8 ([07 문서](07_남은_항목.md)):** 주로 종목 구성 + 기간 운 (종목 점수 순위 폴드 간 상관 0.12). 학습에서 뺀 영향은 평균 +0.017

- **회의 내용:** fold4 처음 보는 10종목 0.418 vs 전체 0.515. 종목 과적합일 수 있음 (재은)
- **이미 확인:** 출렁임 보정은 원인이 아님 (03 문서 3절, 4폴드 합산 0.374 vs 0.471 에서 λ 를 바꿔도 모양이 같음)
- **어떻게:** 규칙은 종목 이름을 안 쓰고 vol20 으로 나누기만 해서 구조상 과적합은 작아야 함. "운인지, 데이터 성질 차이인지"를 봄
  - 낮은 종목(CVS, NFLX, WELL)과 높은 종목(BKNG, BA)의 시간외 봉 수, 평균 \|gap_z\|, ext_range_z, 실적일 수, 갭 이후 되돌림 비율
  - 같은 10종목을 fold1~3 에서도 채점해 순위가 유지되는지 (유지 → 데이터 성질, 바뀜 → 운)
  - 학습에서 다른 10종목을 빼고 다시 돌렸을 때 차이가 비슷한지
