## 3. 이 발표에서 쓰는 말

용어 표를 조금 더 풀어 씁니다.

**갭 (gap)**
- 계산: `마지막 시간외 봉 종가 ÷ 기준일 종가 − 1`
- "마지막 시간외 봉"은 기준일 16:00 이후의 애프터마켓과 다음 날 새벽 프리마켓 봉 가운데, 9:30 전에 확정된 마지막 봉입니다.
- 09:00 봉은 끝나는 시각(known_at)이 09:30 이라 예측 시점과 같습니다. 그래서 `day.price()` 가 자동으로 뺍니다. 실제로 쓰는 마지막 가격은 **08:00 봉 종가**입니다.

**vol20**
- 최근 20거래일 일간 수익률의 표준편차입니다. 0.02 면 "평소 하루에 ±2% 정도 움직인다"는 뜻입니다.

**gap_z**
- 갭 ÷ vol20 입니다.
- 예: 같은 +2% 갭이라도 평소 1% 움직이는 종목이면 gap_z = 2, 평소 4% 움직이는 종목이면 0.5 입니다. 앞쪽이 훨씬 이례적인 움직임입니다.

**ext_range_z**
- (시간외 봉들의 최고가 − 최저가) ÷ 기준일 종가 ÷ vol20 입니다.
- 밤사이 가격이 얼마나 출렁였는지를 나타냅니다. 출렁임이 크면 마지막 가격(갭)이 덜 믿을 만하다고 보고 점수를 조금 깎습니다.

**B 규칙이 학습하는 숫자 5개**

| 숫자 | 뜻 |
|---|---|
| λ | 출렁임으로 얼마나 깎을지 |
| a | 보합과 상승·하락 사이 경계 |
| b | 상승·하락과 급등락 사이 경계 |
| 중앙값, 표준편차 | ext_range_z 를 표준화할 때 쓰는 값 |

후보값을 정해 두고, train 점수가 가장 높은 조합을 고릅니다. 신경망처럼 경사하강으로 배우는 게 아니라 **격자 탐색**입니다.

**디코딩**
- LightGBM 같은 분류 모델은 5등급 각각의 확률을 냅니다. 이걸 실제 등급 하나로 바꾸는 규칙이 디코딩입니다.
- 가장 큰 확률을 고르는 방법(argmax)이 기본이지만, 이 점수식에서는 손해였습니다(7장).

**embargo**
- train 끝과 val 시작 사이를 비우는 것입니다.
- 비우지 않으면 학습 마지막 날과 채점 첫날이 붙어 있어서, 최근 분위기를 그대로 이어받아 점수가 좋게 나옵니다. 실제 평가는 데이터 끝(9/14)과 평가 시작(10/1) 사이가 12거래일 떨어져 있으니 똑같이 맞췄습니다.

**bootstrap**
- 검증 60일 중에서 60일을 **중복을 허용해** 무작위로 다시 뽑고 채점하는 걸 1,000번 반복합니다.
- 어떤 날은 두세 번 뽑히고 어떤 날은 안 뽑힙니다. "검증 기간이 조금 달랐다면 점수가 얼마나 달라졌을까"를 흉내 내는 방법입니다.
- 1,000개 점수 중 가운데 95% 가 들어가는 범위를 95% 구간이라고 부릅니다.

**λ, δ, γ, β, w, κ, θ**
- 모두 "규칙에 어떤 정보를 더할 때 얼마나 세게 반영할지"를 정하는 숫자입니다.
- 후보에 0 이 항상 들어 있어서, 0 이 골라지면 "train 데이터로 보니 그 정보는 안 쓰는 게 낫다"는 뜻입니다. 각 기호의 쓰임은 부록 A2 표 머리를 보면 됩니다.

## 4. 점수식

**이 장이 말하는 것**
점수는 거의 "크게 움직인 날 방향을 맞혔느냐"로 정해집니다.

**가중치 표가 왜 이렇게 생겼나**
가중치 w = (정답 − 예측)² × (|정답 − 2|)² 입니다. 앞부분과 뒷부분이 각각 하는 일이 다릅니다.

- **앞부분 (정답 − 예측)²: 얼마나 멀리 틀렸나**
  - 한 칸 틀리면 1, 두 칸이면 4, 네 칸이면 16 입니다.
- **뒷부분 (|정답 − 2|)²: 정답이 얼마나 극단인가**
  - 정답이 보합(2)이면 0 이라, 그 줄 전체가 0 이 됩니다.
  - 정답이 상승·하락이면 1, 급등락이면 4 입니다.

그래서 정답이 급하락(0)이고 급상승(4)으로 찍으면 4² × 2² = 64 입니다.

**분모(무작위 기대 벌점)를 직관적으로**
1. 우리가 찍은 등급의 비율은 그대로 둡니다. 예를 들어 급하락 21%, 하락 18%, 보합 17%, 상승 19%, 급상승 25% 입니다.
2. 어느 날 어느 종목에 무엇을 찍을지만 무작위로 섞습니다.
3. 그때 받을 벌점의 기댓값이 분모입니다.

수식은 `E[i][j] = (정답이 i 인 행 수) × (j 로 찍은 행 수) ÷ 전체 행 수` 이고, 분모는 Σ w·E 입니다.

**왜 분모가 중요한가**
- 급등락을 많이 찍으면, 틀릴 때 벌점이 큰 칸에 행이 더 들어가서 분모도 커집니다.
- 그래서 "급등락을 많이 찍는다 = 무조건 위험"이 아닙니다. 그 비율로 무작위로 찍은 것보다 얼마나 나은지가 점수입니다.
- 반대로 전부 보합만 찍으면 분자와 분모가 둘 다 0 근처라 점수가 0 입니다.

**fold4 계산**
- 실제 벌점: Σw·O = 9,389
- 무작위 기대 벌점: Σw·E = 19,376
- 점수: 1 − 9,389 ÷ 19,376 = 1 − 0.485 = **0.515**

**"19.5%" 는 무엇인가**
fold4 검증 기간에 실제로 급하락이나 급상승이었던 행의 비율입니다. 하나씩 보면 급하락 8.4%, 급상승 11.2% 입니다. train 기간(13.6%)보다 높습니다.

**받을 수 있는 질문**
- *보합을 많이 찍으면 안전하지 않나?*
  - 보합으로 찍으면 정답이 급등락일 때 16(급하락→보합, 급상승→보합)이 붙습니다.
  - 분모도 같이 작아지므로 점수가 0 쪽으로 갑니다. 실제로 LightGBM 을 argmax 로 찍었을 때 보합 37% → 0.433 이었습니다.

## 5. 검증 설계

**이 장이 말하는 것**
점수를 믿을 수 있게 만든 장치들입니다.

**폴드 표 읽는 법**
- 날짜는 전부 **기준일**(예측을 만드는 날의 전날 = 정답이 확정되는 날의 하루 전 거래일)입니다.
- train 은 항상 2024-08-13 부터 시작하고, 폴드가 갈수록 길어집니다(197 → 377일). 이런 방식을 expanding window 라고 합니다.
- val 은 각 60거래일, 약 3개월입니다.

**fold4 만 주 지표인 이유 (가장 자주 받을 질문)**
- 세 사람의 EDA 는 대상일 2026-02-13 까지의 데이터를 보고 "갭이 방향을 알려 준다", "변동성이 크기를 알려 준다" 같은 결론을 냈습니다.
- 그 결론으로 피처와 규칙을 만들었으니, 같은 기간으로 채점하면 이미 본 데이터로 시험을 보는 셈입니다.
- fold1~3 의 val 은 모두 이 기간 안에 있고, fold4 의 val(2026-03-04 ~ 05-28)만 바깥입니다.

**guard 는 무엇인가**
- `lab/leak.py` 의 `guard(day)` 는 `day` 객체를 감싸서, 대상일 09:30 이후에 알 수 있는 데이터를 요청하면 오류(`LeakError`)를 냅니다.
- 모든 val 예측이 이걸 거치므로, 점수가 나왔다는 것 자체가 "누수 없음"의 증거입니다.

**처음 보는 종목 10개**
- 평가에서 50종목 중 10개 + 새 종목 10개가 나온다고 했습니다(과제 설명).
- 새 종목 상황을 흉내 내려고 10개를 무작위로 골라 학습에서 뺐습니다. 고르는 시드는 2026 입니다.
- 이 10종목은 val 에서만 채점하고, 그 점수를 "unseen" 으로 따로 기록합니다.

**채택 기준이 왜 세 개인가**

| 조건 | 막으려는 것 |
|---|---|
| fold4 하락 없음 | 주 지표가 나빠지는 변경 |
| 3/4 폴드 상승 | 한 시기에만 좋은 변경 |
| 평균 +0.005 | 무작위 흔들림 수준의 차이 |

이 기준은 실험 전에 정했고, 결과를 보고 바꾸지 않았습니다.

## 6. 방향은 갭, 규칙은 다섯 칸으로 자른다

**이 장이 말하는 것**
규칙 점수 s 가 클수록 실제로 오른 비율이 높습니다. 규칙은 s 를 경계 a, b 로 잘라 5등급을 찍습니다.

**그림을 만든 방법**
1. fold4 의 train 기간(처음 보는 종목 제외) 15,040행에 대해 규칙 점수 s 를 계산했습니다. 경계와 λ 도 이 train 으로 정한 값입니다.
2. s 를 작은 것부터 줄 세우고, 행 수가 같도록 12묶음으로 나눴습니다. 한 묶음에 약 1,250행입니다.
3. 묶음마다 실제 등급의 비율을 쌓은 막대가 그림입니다.

x축 숫자는 그 묶음에 들어간 s 의 범위입니다. 묶음 폭이 일정하지 않은 건 행 수를 맞췄기 때문입니다.

**점선 네 개**
s = −b, −a, +a, +b 위치입니다. s 가 −b 이하면 급하락, −b ~ −a 면 하락, −a ~ +a 면 보합, +a ~ +b 면 상승, +b 이상이면 급상승으로 찍습니다.

**읽을 거리**
- **왼쪽 끝 묶음:** 실제 급하락이 28%, 하락까지 합하면 59% 입니다.
- **오른쪽 끝 묶음:** 실제 급상승이 28%, 상승까지 합하면 66% 입니다.
- **가운데:** 보합(회색)이 40% 안팎으로 가장 많습니다.

즉 s 의 부호는 방향을 꽤 맞히지만, 극단 묶음에서도 실제 급등락은 30% 가 안 됩니다.

**"행의 40% 를 급등락으로 찍는다"의 의미**
- |s| ≥ b 인 행이 40% 입니다. 실제 급등락(train 13.6%)의 약 3배입니다.
- 4장의 분모 효과 때문에, train 에서 경계를 이렇게 낮게 잡는 게 점수가 가장 높았습니다.
- 크게 찍어서 맞으면 벌점이 크게 줄고, 틀려도 분모가 같이 커지는 구조라 가능한 일입니다. 다만 방향을 반대로 찍으면 크게 잃습니다(8, 9장).

**받을 수 있는 질문**
- *EDA 의 IC 0.30 은 무엇인가?*
  - 날마다 50종목의 갭 순위와 그날 수익률 순위의 상관(순위 상관)을 구해 평균한 값입니다.
  - 0 이면 관계 없음, 1 이면 순위가 완전히 같음입니다. 주가 예측에서 0.30 은 매우 높은 편입니다.

## 7. 실험 여정

**이 장이 말하는 것**
실험을 일곱 묶음으로 했고, 어느 묶음도 B 규칙을 확실히 넘지 못했습니다.

**그림 읽는 법**
- y축은 실험 묶음, x축은 fold4 점수입니다.
- 묶음 안에서는 점수 순서대로 위아래로 살짝 흩어 놓았습니다(겹치지 않게).
- 각 묶음에서 가장 높은 실험 하나에 이름과 점수를 붙였습니다.
- 회색 띠는 무작위 예측 점수의 ±2 표준편차(약 ±0.06)입니다.

**묶음별로 무엇을 시험했나**

| 묶음 | 가설 | 결과 |
|---|---|---|
| 기준선 | 정보 없이 찍으면 얼마인가, 갭 하나면 얼마인가 | 무작위·보합 ≈ 0, 장전 등락만 0.306, 갭 0.511 |
| B 규칙 | 갭을 변동성으로 나누고, 출렁임으로 보정하면 낫다 | 0.512 → 0.515 |
| LightGBM 디코딩 | 피처 26개를 쓰는 모델이 규칙보다 낫다 | argmax 0.433. 디코딩을 바꿔 0.495 까지. 그래도 규칙 아래 |
| C 텍스트 | 뉴스·Reddit 이 크기 정보를 더한다 | LightGBM 에 넣으면 fold4 −0.002 ~ −0.025 |
| v2 선형·트리 | 손실 함수를 바꾸면(Huber, L1, 순서형, 가중) 낫다 | 최고 Huber 선형 0.507 |
| v2 규칙+정보 | 규칙은 그대로 두고 정보를 조금씩 얹는다 | 최고 +0.001 (atr14) |
| v3 | 시장 갭 분리, 시장 국면, 최근 기간만 학습 | 최고 +0.007 (winvote) |

**"디코딩만 바꿔 +0.062" 가 중요한 이유**
같은 LightGBM 모델, 같은 확률에서 찍는 방법만 바꿨습니다.

| 방법 | 어떻게 찍나 | fold4 |
|---|---|---|
| argmax | 가장 큰 확률의 등급. 보합 확률이 대체로 가장 커서 보합을 37% 찍음 | 0.433 |
| match_train | 기대 등급(Σ 등급 × 확률)을 줄 세우고, train 의 실제 등급 비율대로 자름 | 0.478 |
| aggr | 그 비율에서 급등락은 k 배, 보합은 1/k 배로 바꿔 자름. k 는 train 마지막 40일로 고름 | 0.495 |

모델 종류를 바꾸는 것보다 이 차이가 컸습니다. 이 점수식에서는 "확률을 잘 맞히는 것"과 "점수를 잘 받는 것"이 다르다는 뜻입니다.

## 8. 왜 안 오르나 ① 벌점의 출처

**이 장이 말하는 것**
규칙의 벌점 절반은 소수의 "방향을 정반대로 찍은" 행에서 나오고, 그 행들은 개장 전 정보로는 구분이 잘 안 됩니다.

**오른쪽 막대 그림 (먼저 볼 것)**
fold4 검증 3,000행(50종목 × 60일)을 세 종류로 나눴습니다.

| 종류 | 조건 | 행 비율 | 벌점 비율 |
|---|---|---|---|
| 반대 방향 | 정답 급하락인데 상승·급상승으로 찍음, 또는 정답 급상승인데 하락·급하락으로 찍음 | 3.2% (96행) | 51% |
| 보합으로 놓침 | 정답 급등락인데 보합으로 찍음 | 1.5% (44행) | 7% |
| 나머지 | | 95% | 41% |

**왼쪽 막대 그림**
- 정답이 급등락인 행만 모았습니다(575행). 이 행들을 |gap_z| 크기로 나눠, 갭 방향과 실제 방향이 같았던 비율을 봤습니다.
- |gap_z| 가 0.25 미만이면 68%, 0.5~1 이면 91%, 2 이상이면 100% 입니다.
- 갭이 크면 방향은 거의 맞고, 작으면 맞힐 확률이 많이 떨어집니다.

**"갭이 작아서 틀린 게 아니다"는 무엇과 비교했나**
- 반대로 찍은 96행의 |gap_z| 중앙값은 0.26, 전체 3,000행은 0.24 입니다.
- 왼쪽 그림만 보면 "작은 갭에서 틀린다"고 생각하기 쉽습니다. 하지만 반대로 찍은 행들의 갭 크기는 평범했습니다. 즉 아침에 이미 꽤 움직여 있었는데 장중에 반대로 크게 간 경우입니다.

**날짜 쏠림**
- 60일 중 벌점이 가장 큰 5일(대상일 2026-04-10, 03-27, 03-06, 04-01, 03-18)이 벌점의 22% 입니다.
- 벌점이 날짜에 고르게 퍼져 있었다면 5/60 = 8% 였을 겁니다.
- 이런 날은 여러 종목이 같은 방향으로 뒤집혔다는 뜻이라, 시장 전체 사건(지표 발표, 정책 뉴스 등)이 장중에 있었을 가능성이 큽니다. 이건 아직 확인하지 않은 추정입니다.

**코드**: `scripts/analysis_figs.py` 의 `fig_errors()`

**조심할 점**
- 96행은 작은 표본입니다. "실적일 1행" 같은 비율은 방향만 참고해 주세요.

## 9. 왜 안 오르나 ② 크게 찍기의 비대칭

**이 장이 말하는 것**
크게 움직일 걸 알아도 방향을 모르면 크게 찍는 건 손해이고, train 도 그렇게 답했습니다.

**왼쪽 그림의 계산**
가중치 표의 4열(급상승) − 3열(상승)입니다.

| 정답 | 상승으로 찍었을 때 | 급상승으로 찍었을 때 | 차이 |
|---|---|---|---|
| 급하락 | 36 | 64 | +28 |
| 하락 | 4 | 9 | +5 |
| 보합 | 0 | 0 | 0 |
| 상승 | 0 | 1 | +1 |
| 급상승 | 4 | 0 | −4 |

맞았을 때 아끼는 벌점은 4 인데, 정반대였을 때 늘어나는 벌점은 28 입니다(7배). 민영 PDF §4 의 "손실 7배"와 같은 계산입니다.

**"직접 해 봄" 상자**
- 규칙이 상승으로 찍은 575행의 실제 결과는 급하락 23, 하락 166, 보합 180, 상승 155, 급상승 51 입니다.
- 이걸 전부 급상승으로 바꾸면 분자 변화는 23×28 + 166×5 + 180×0 + 155×1 + 51×(−4) = 644 + 830 + 0 + 155 − 204 = **+1,425** 입니다.
- 분모도 바뀌어서 최종 점수는 0.494 입니다(직접 다시 채점한 값).

**오른쪽 표 (δ) 를 만든 방법**
1. 규칙의 방향과 보합 경계 a 는 그대로 둡니다.
2. 급등락 경계만 `b × exp(−δ × z(피처))` 로 바꿉니다. z(피처)는 train 기준으로 표준화한 피처 값입니다.
3. δ 후보는 −0.3 ~ +0.3(0.1 간격)이고, a·b 후보와 함께 train 점수가 가장 높은 조합을 고릅니다.

δ 의 부호에 따라 이렇게 움직입니다.
- **δ > 0:** 피처 값이 클수록 경계가 낮아집니다. 급등락을 더 쉽게 찍습니다.
- **δ < 0:** 피처 값이 클수록 경계가 높아집니다. 급등락을 덜 찍습니다.
- **δ = 0:** 그 피처를 쓰지 않습니다.

코드: `work/a/models2.py` 의 `fit_rule_size`. 실험 이름은 `v2_rsize_*`, `v3_rsize_*` 입니다.

**표 해석**
- 실적일, 시장 갭이 큰 날, 급등락이 잦은 종목, atr14 가 큰 종목은 모두 **크게 움직일 가능성이 높다는 신호**입니다(EDA 에서 확인한 것). 그런데 train 은 이 신호가 클 때 급등락을 **덜** 찍는 쪽을 골랐습니다.
- 이유는 왼쪽 계산과 같습니다. 크게 움직여도 방향이 반반이면, 급등락으로 찍었을 때 맞아서 아끼는 벌점(4)보다 틀려서 늘어나는 벌점(28)이 큽니다.
- 시장 20일 변동성만 반대(δ > 0)였습니다. 시장 전체가 크게 움직이는 시기에는 갭의 방향도 대체로 유지돼서, 급등락을 더 찍는 게 나았던 것으로 보입니다. 이 부분은 추정입니다.

**조심할 점**
- 이 δ 들로 검증 점수가 오르지는 않았습니다(fold4 차이 −0.005 ~ +0.001).
- "train 이 이렇게 골랐다"는 건 정보를 쓰는 방향에 대한 증거이지, 점수 향상의 증거가 아닙니다.

## 10. 왜 안 오르나 ③ LightGBM 도 같은 걸 본다

**이 장이 말하는 것**
LightGBM 이 배운 것도 "방향은 갭, 크기는 변동성"이라 규칙과 사실상 같습니다.

**세 그림의 차이**

| 그림 | 무엇을 쟀나 | 한계 |
|---|---|---|
| gain 중요도 (회색) | 트리가 그 피처로 나눌 때 손실이 줄어든 양의 합 | 방향이 없음. "많이 썼다"만 알 수 있음 |
| 방향 기여 (초록) | 그 피처가 "급상승 확률 − 급하락 확률"(logit)에 더한 값의 절댓값 평균 | |
| 크기 기여 (주황) | 그 피처가 "보합 확률"(logit)을 깎은 값의 절댓값 평균 | |

**pred_contrib 란**
- LightGBM 의 `predict(..., pred_contrib=True)` 는 각 행의 예측값(등급별 logit)을 "기본값 + 피처별 몫"으로 정확히 나눠 줍니다. SHAP 값과 같은 계산(TreeSHAP)입니다.
- `shap` 패키지를 따로 설치하지 않고 LightGBM 에 내장된 기능을 썼습니다.
- 대상은 fold4 LightGBM 을 다시 학습한 모델과 fold4 val 3,000행입니다(반복 54회, k 2.5).

**"값과 기여 상관 0.79~0.83"**
- gap, gap_z, gap_rel_z 각각에 대해, 피처 값과 그 피처의 방향 기여 사이 상관입니다.
- 양수이고 크다는 건 "갭이 클수록 급상승 쪽으로 민다"가 일관되게 성립한다는 뜻입니다. 부록 A7 산점도가 gap_z 의 예입니다.

**"순위 상관 0.85~0.96"**
- 같은 실험에서 fold1~4 의 중요도 순위를 서로 비교한 스피어만 상관의 평균입니다.
- 1 에 가까우면 폴드마다 같은 피처를 같은 순서로 중요하게 쓴다는 뜻입니다.

**텍스트 비중 4.8%**
- `ablation_struct+text_all_aggr`(C 텍스트 7개를 모두 넣은 실험)에서, 중요도 합을 1 로 맞췄을 때 텍스트 피처 7개 몫의 합입니다(4폴드 평균).
- 단어 목록·TF-IDF 를 넣은 `v2_lgb_huber_b26_lex_tfidf` 에서는 3.4% 입니다.

## 11. 노이즈 바닥

**이 장이 말하는 것**
점수가 0.005 정도 다른 건 지금 데이터로 구분할 수 없습니다.

**왼쪽 그림: 무작위 1,000번**
- fold4 val 정답은 그대로 두고, 예측만 5등급 중 무작위로 1,000번 찍어 채점했습니다.
- 평균은 0 근처이고 표준편차는 0.029 입니다. 정보가 전혀 없어도 점수가 ±0.03 정도는 그냥 흔들린다는 뜻입니다.
- worklog 의 "±0.07" 은 다른 숫자입니다. W&B 의 무작위 run 하나가 폴드마다 −0.07 ~ +0.02 를 오간 범위입니다.

**규칙 점수의 bootstrap 범위 0.42 ~ 0.59**
- 규칙 예측은 그대로 두고, 검증 60일을 중복 허용으로 다시 뽑아 채점하는 걸 1,000번 반복했습니다.
- 범위가 넓은 이유는 8장의 "날짜 쏠림" 때문입니다. 벌점이 큰 날이 몇 번 뽑히느냐에 따라 점수가 크게 바뀝니다.

**오른쪽 그림: 가짜 피처 30번 vs 실제 실험**
- **가짜 피처 만들기:** atr14 의 값을 행끼리 무작위로 섞었습니다. 값의 분포는 같지만 그날 그 종목과의 관계가 끊긴, 의미 없는 피처가 됩니다.
- **실험:** 9장과 같은 절차(급등락 경계 이동, δ 를 train 이 고름)로 fold4 를 채점하는 걸 섞는 순서를 바꿔 30번 했습니다.
- **결과:** 28번은 train 이 δ = 0 을 골라 규칙과 똑같았고, 나머지 2번도 차이가 −0.009 ~ +0.002 였습니다.
- **비교:** 아래 줄이 실제 v2·v3 실험들이고, 규칙과 같은 점수(차이 0)인 실험은 뺐습니다. 오른쪽 끝(+0.005 ~ +0.007)에 있는 세 점이 recent250, recent120, winvote 입니다.

여기서 읽을 수 있는 것은 두 가지입니다.
1. 우리 선택 절차는 의미 없는 정보를 잘 걸러냅니다.
2. 실제 피처들(실적일 +0.0001, atr14 +0.001)이 낸 차이는 가짜 피처가 낸 차이와 구분이 안 됩니다.

**recent250 − 규칙 bootstrap**
- 같은 날짜 표본으로 두 모델을 함께 채점하고 차이를 기록하는 걸 1,000번 반복했습니다(짝지은 비교).
- 차이의 95% 구간은 −0.002 ~ +0.014, 0 이하로 나온 비율은 9% 입니다.
- "91% 는 recent250 이 낫다"고 읽을 수 있지만, 두 가지를 같이 봐야 합니다.
  - 오른 달이 4·5월 두 달뿐입니다.
  - 53개 실험 중 가장 좋은 걸 골라서 본 숫자라, 고르는 과정 자체가 점수를 부풀립니다.

  - f1~f4 는 폴드별 점수, unseen 은 fold4 의 처음 보는 종목 점수, "vs 규칙 f4" 는 B 규칙(`rule_gapz_ext`)과의 fold4 차이입니다.
- **`v2_rule_base` 가 `rule_gapz_ext` 와 다른 이유**
  - λ 후보만 다릅니다(0~0.4 vs 0~0.5). fold4 는 같고(0.5154) fold1 만 다릅니다(0.4475 vs 0.4344).
- **규칙과 점수가 완전히 같은 v2 실험이 많은 이유**
  - train 이 추가 정보의 가중치를 0 으로 골라서 규칙과 똑같은 예측이 나왔기 때문입니다(A2).

### A2. 학습된 파라미터

| 기호 | 쓰임 | 0 이면 |
|---|---|---|
| λ | 출렁임(ext_range_z)으로 갭을 깎는 정도 | 깎지 않음 |
| γ | 어떤 정보로 갭 신뢰도를 조절 `exp(γ·z)` | 신뢰도 조절 안 함 |
| δ | 급등락 경계 이동 (9장) | 경계 그대로 |
| β | 텍스트 방향 점수를 규칙 점수에 더하는 비중 | 더하지 않음 |
| w | 규칙 + Huber 선형 모델 앙상블에서 선형 모델 비중 | 규칙만 씀 |
| κ | 시장 전체 갭을 빼는 정도 | 빼지 않음 |
| θ | 프리마켓 안 등락을 더하는 비중 | 더하지 않음 |

- 강조된 줄은 추가 정보의 가중치가 0 이 아닌 폴드가 있는 실험입니다.
- 0 이 아닌 값이 골라졌어도 검증 점수는 오르지 않았습니다.

### A3. 점수식 분해

- 왼쪽 막대는 정답 등급별로 실제 벌점(색)과 무작위 기대 벌점(회색)을 나란히 놓은 것입니다. 정답 보합 줄은 둘 다 0 입니다.
- 오른쪽 열지도는 칸마다 (LightGBM 벌점 − 규칙 벌점) ÷ 분모를 %p 로 표시한 것입니다. 빨간 칸이 LightGBM 이 더 잃은 곳이고, 정답 급상승 줄과 급하락 줄에 몰려 있습니다.

### A4. 폴드별 점수

- 네 폴드 모두 B 규칙 > LightGBM > pre_move 규칙 > 무작위 순서입니다.
- fold4 가 다른 폴드보다 높은 건, 그 기간 급등락이 많아서(19.5%) 갭으로 맞힐 거리가 많았기 때문으로 보입니다.

### A7. gap_z 기여 산점도

- 점 하나가 fold4 val 한 행입니다. x 는 gap_z(±4 로 자름), y 는 gap_z 가 "급상승 logit − 급하락 logit" 에 더한 몫입니다.
- 0 근처에서 급하게 오르고 양 끝에서 평평해집니다. 갭이 0 에서 조금만 벗어나도 방향 판단이 바뀌고, 아주 큰 갭은 더 커져도 추가 효과가 적다는 뜻입니다.
